# SoloRxjh

面向Windows的3D单机武侠修仙RPG，正式名称待定。目标技术栈为 **Godot 4.7.2标准版 + GDScript**；登录/选角、职业成长、武器装备、武功气功、物品、强化合成、怪物、任务和披风等系统参考《热血江湖》官网，界面和视听使用现代化原创设计。

故事保留方尘、琉璃剑宗、千竹岭与浮仙剑的来源，自建角色与新增剧情明确作为游戏改编。本地登录表示选择本机档案，游戏离线运行，没有服务器、数据库或联网账号依赖。

## 当前状态

2026-11-13文档阶段D0已通过：原文档整合为12份主文档，官网参考、系统规则、数据、开发顺序及验收标准已统一。工作区程序仍为Rust/Bevy，Godot工程和新增系统尚未实现；旧Windows预览包不代表目标版本。下一步为P1引擎与工程，实际状态见[实施与验证记录](docs/09-实施与验证记录.md)。

执行顺序为：**文档与官网参考 → 程序实现 → 系统功能测试 → 美术与现代界面 → 最终交付**。阶段通过后再继续，直到约定系统完成。桌面物理操作继续停止，不修改数据库或用户真实存档。

## 完整系统范围

- 本地档案、角色创建/选择/删除、八职业、1～60级、10/35/60级晋级与正邪路线。
- 三地区探索、鼠标/WASD移动、连击、职业武功/气功、怪物AI、精英/首领、采集和掉落。
- 八类武器系列、11槽装备、六类披风、物品分类、背包/仓库、交易、强化/合成/洗炼/转移/制造。
- 主线与区域任务、重复委托、门派贡献和晋升、地图路标、本地消息、设置和可靠存档。
- 现代登录/创建/选角、HUD与完整面板，高质量角色/武器/披风、场景、动作和视听反馈。

## 技术方案

| 部分 | 目标技术 |
| --- | --- |
| 引擎/语言 | Godot4.7.2标准版、类型化GDScript |
| 3D与逻辑 | Forward+/Vulkan、场景节点/信号、60Hz固定步 |
| 界面 | Control/Container/Theme、CanvasLayer、InputMap与中文IME |
| 配置/存档 | 严格JSON配置、FileAccess/DirAccess、本地档案与角色快照 |
| 资源 | Blender→GLB、AnimationPlayer/AnimationTree、Skeleton3D与骨骼挂接 |
| 音频 | AudioServer、AudioStreamPlayer/3D与独立总线 |
| 验证/交付 | 无窗口规则/场景测试、原生渲染、Windows x64导出与资源清单 |

Godot版本[官方发布页](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable)已核对。工程、命令及模板实际准备完成前，不将技术方案标为已实现。
