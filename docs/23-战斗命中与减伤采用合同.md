# 战斗命中与减伤采用合同

更新日期：2026-11-14。状态：**项目设计，未实现、未校准**。[战斗参数JSON](contracts/战斗命中与减伤.v1.json)是本页精确规则的唯一数据源。所有公式、基础概率和闪避数值均为项目选择，不冒充官网公式；完整气功、装备、怪物及其他主动能力仍须逐项绑定。

## 1. 判定、命中与随机

先验角色存活、目标/动作身份、阵营关系、场景、几何、遮挡、安全区和闪避窗口，再消费随机。玩家不互相伤害；NPC武者对抗仍是明确PvE上下文，不能按人形模型或派别名称判断PVP/PvE。缺少战斗关系标签是配置错误，不补成敌人。

攻击命中率基点为`9000+10×(攻击者命中评分−目标回避评分)+已登记的适用命中概率修正`，合法计算结果按玩法明确限制到500～9900，即5%～99%。[66首饰](66-普通首饰基础与贡献采用合同.md)的武功命中/回避与具名气功概率修正统一在最终封顶前加减，只在各自明确事件范围适用；评分百分比先形成评分，不乘命中概率。每段/目标仅判一次，整数随机0～9999，小于概率才命中。评分是非负整数；封顶是命中玩法，不用于修复非法字段。

未命中不抽攻击区间或暴击，也不给出血/充能/攻击怒气；已提交成本和冷却不返。命中后从22合同动作攻击区间均匀取整数（含两端），单值不抽随机；区间已含武器及对应PvE攻击，不能另加武器或用平均值代替。基础暴击率5%、倍率1.5，作用普通/攻击武功，恢复、周期和状态爆发不暴击。暴击最终概率必须合法0～10000，不从未知气功补概率。

接受动作时可先有[怒海等明确动作快照触发](contracts/狂暴与低生命攻击气功.v1.json)，在合法付费后保存一次判定；真正命中阶段顺序为命中、区间、暴击，再是明确受击/命中回调和反气功顺序。未命中不会退回较早的接受动作判定；不得依客户端消息到达顺序抽随机。每笔消费位置与结果一起提交，重发/重连不重抽。未命中、免疫、无效几何各有明确结果，不能一律显示“命中但0伤害”。

## 2. 直接伤害与防护顺序

直接攻击使用已接受动作的攻击区间快照：[7项威力合同](contracts/武功威力气功采用.v1.json)先在技能平量分量加明示平量/百分源，才与取值攻击相加并乘段倍率；之后暴击及命中时增伤结算。66首饰追伤仅根动作主目标首次合格命中按快照加一次，位于这些倍率之后、明确防御前guard和普通防御之前；不再乘暴击/段倍率，仍走后续减伤，不为它另发命中事件。不在总和上重乘已处理的武功威力气功。来源稳定排序，逐项取整；不能将已乘过的伤痕、血魔增伤再乘入派生出血。接受动作后反气功降低某气功，不追改已付费动作快照或退费；之后新动作读新值。

有效防御为普通防御加本次PvE防御；防御必须非负。防御阶段为`整除(防御前伤害×100,100+有效防御)`，0防御无此减伤，100防御剩一半。反气功预算×2和宝珠PvE防御各作为独立来源加入一次；不能误作百分比或同时加进普通/独立两栏。

直接攻击武功先按[本地罡气评分](contracts/精金血气与罡气采用.v1.json)额外结算一次独立抗性，非武功类型不套；之后依次为明确固定减伤（最低0）、符合7项合同的格斗非连击对怪最终附加、明确百分比保护、甄凤柏已生效护盾、梅柳真障力、生命。护盾按20合同30%向上取整抵伤，障力按14合同向上取整并限制实际障力量；此处不另做一次防御。允许最后伤害为0，不强制至少1点穿透护盾。当前生命损失不超过原剩余生命，超额不作为吸血/怒气/出血/奖励贡献。

例：200点防御前伤害、100普通防御和44反气功对怪防御，防御后81；30%护盾抵25后56；基础5%障力抵3后生命损失53、障力耗3。这是组合顺序算例，不代表普通单职业同时拥有两种职业资源；组合能力只有明确配置才合法。

所有乘加先检查精确整数范围，不将JSON超精度或中间溢出包成0伤害。玩法中的明确上限和合法0结果与输入拒绝分开。未定义的固定/百分减伤来源不能被程序临时当0或自动按任意顺序相乘。

旧剑气/穿云刺明确使用[旧剑技固定威力档](contracts/旧剑技兼容.v1.json)：基础+人物等级增长+技能等级增长先形成原始威力，不加攻击区间、不抽区间/暴击；命中后仍走本页防御/保护。它是具名兼容例外，不用于缺少攻击参数的其他技能兜底。旧护体明确接百分减伤段、回春是自疗而非攻击。

[气沉丹田](contracts/气沉丹田采用.v1.json)的13职业转化保护只处理明确直接攻击武功；谭花灵分支在命中/普通防御/固定减伤后、百分保护前独立判50%减伤，不加转化HP。两分支依具名配置，临时有效等级0不退款，坏循环属性引用拒绝，不拿概率分支兜底转化失败。

## 3. 周期、状态与死亡

出血已从实际伤害取快照，后续跳数不再判普通命中、暴击或扣第二遍普通防御；神女烧伤、超负荷、阎王爆先按20合同比例/伤害上限形成基础值，再走明确状态保护。适用的甄凤柏敌方伤害护盾仍可抵消，梅柳真障力只抵直接敌方攻击，不抵周期/自付生命。不同来源的标签必须显式定义，不能把所有带数字的状态都塞普通攻击流程。

周期不制造攻击动作，不再触发出血、攻击怒气、反气功或充能；真实生命损失可以给受害者基础受伤怒气及活动伤害记录。自付生命不是伤害，不触发防护/受击或死亡拦截；施法费用须留1生命，血雨恶魔明确0费覆盖按14/20执行。

致命伤先判显式合格拦截，失败才标死；已标死目标后续同帧伤害/治疗都不再改变其生命。以第一次提交终结死亡的事件记录归属，动作/目标/段或根事件/周期序号去重。宠物奖励归属可以归主人，但宠物实体不是本人，不能让其代杀满足血魔。相同步按稳定动作/根事件ID、段/周期序号、目标ID处理，活动期限末步血魔裁决遵20规则。

只有实际生命损失才能产生新出血/充能/攻击怒气；障力完全承担的直接命中仍可按其被动条件判断障力恢复，主目标活着且有对应气功的反气功仍可判，不能把“0生命损失”和“未命中”混为同一结果。

[反伤/吸血回调](contracts/反伤与吸血采用.v1.json)先完成根伤害/致命处理，再按稳定气功ID跑仍存活防守者回调，最后仍存活攻击者吸血；反伤杀死攻击者则不能再用原命中回血复活。派生伤害带明确reflection/lifedrain标签，不重做普通防御/暴击或制造攻击回调，专用反弹减伤和护盾只算一次；根动作结果/派生结果与随机收据一起去重。

[恢复/内力气功](contracts/恢复与内功消耗气功.v1.json)给恢复和费用分支唯一合成顺序：治疗施法快照增幅一次、落效复验封锁/缺失量；内力基础费乘太极及最强辅助减耗后只向上取整一次，再走血魔明确零费覆盖和可付费检查。不得把攻击暴击/区间套入恢复、把生命/道具费用也减掉，已付动作不因后来等级变化补扣或退款。

[护身/破甲具名顺序](contracts/护身与破甲采用.v1.json)明确护身对怪/武者互斥，医转防作为无反馈普通防御源，无坚暂减防不改持久基表；防御后格斗平量保护/具名霸气附加分别一次，然后显式百分保护族稳定排序。命中、源防御锚、受击触发和额外伤害各有收据，不凭技能名多跑一个完整攻击流程。

[卢转攻的本次防御试算](contracts/转攻与乾坤气功采用.v1.json)在当前命中原伤害快照已确定时只计算一次，不提交试算生命损失/怒气/奖励；成功替换自身转防源后才执行真实减伤和后续防护。失败仍用旧合法来源，不能把试算当真实伤害再扣一次；枪/格斗分支受伤后才改变后续属性。

[甄内功联动](contracts/甄凤柏内功联动气功.v1.json)将受怪攻击20内功防护挂防御前唯一受击费用槽，预览防御不能再扣；夜魔30%在后续具名百分保护一次。内功血雨额外500是具名气功费用例外，只按太极减耗、不跟普通施法血魔0费自动免除，已接受动作保存差量和支付结果；绝脉运气只加技能平量威力。

[刺客/弓超必杀](contracts/刺客必杀与超必杀气功采用.v1.json)在允许暴击的根攻击上，用同一整数抽数的互斥区段选择超必杀、普通暴击或普通命中，不额外乘普通暴击。超必杀不是技能的finishing_martial标签，格斗暴击/致命保护最多一次；无暴击固定威力/派生/治疗档不自动开放。

[28升天角色类型](28-升天武功与秘籍采用合同.md)明确刺客根普攻平量只加一次、弓副箭为派生无攻击触发，骨折/出血用独立负面状态而非额外完整攻击；卢挡怪在几何/闪避后、命中随机前每根一次，格挡成功不再抽命中/暴击。相同根收据贯穿普通及派生，不把初始化后旧持续自增益保留成高阶段。

[29杀星/尸毒](29-神女杀星与尸毒气功采用合同.md)将杀星平量置武功平量合成后且只用于首次主目标真命中；尸毒是独立状态周期/死亡爆发，不另扣普通防御、不借绝命收益或阎王反射。每次死亡先截取最强源与位置，完成本步普通根/周期后按稳定顺序处理一轮尸毒爆发，再清理；爆发致死禁止再次排尸毒波，施加者活体/同实例资格在波执行时复验。

形移、云心、霸王及远距泡的唯一effects.defense沿[严格四防护组件](contracts/防护效果状态.schema.json)与医师原persistent_defense_state；[life_state/timers/defense联验](contracts/防护效果联合.schema.json)要求死亡清效果但保冷却、活跃效果有同profile正成功冷却，实际同根和余时差另查原事件。火凤保10不生成持续免伤。云心仅保存正容量活跃池，破裂事实/扣罚只在原结果：先移除耗尽池，剩余敌伤完成原扣血/致命拦截/唯一死亡，再对仍存活者执行一次不可拦截破罩扣血；已死则记录跳过不再造死亡，恢复回调最后且只对活者。自然到期/安全清除不扣罚，换装或重放不填池。

## 4. 闪避

闪避花20体力，动作24步，冷却60步，按接受时归一化方向位移3米；无输入用当前前向。第4～12步（含）免直接敌方攻击，不免周期、环境或自身费用。移动使用连续扫掠碰撞，阻挡则滑动/停止，不穿墙补足3米。资源不足、死亡、硬控制或不兼容已提交动作拒绝；菜单、药品和重复请求不刷新冷却。闪避正式采用[六键请求](contracts/闪避请求.schema.json)、[十八键动作根](contracts/玩家闪避.schema.json)、[十二键接纳结果](contracts/闪避接纳结果.schema.json)和[十一键推进结果](contracts/闪避推进结果.schema.json)。接纳当步e0不移动，后续每真实scope步125毫米，推进后e4～12用于本步直接攻击免疫；受阻损失不追偿。死亡/真实迁移/正式会话结束沿[十一键中断结果](contracts/闪避中断结果.schema.json)保最后真实步并释放占用，不退款、不刷新冷却；暂停/临时失联不伪造中断，自然完成不另造终止事件。冷却唯一保存于character.timers.intrinsic_cooldowns.dodge，正剩余与原已提交闪避接纳事件同笔登记，沿[冷却根](contracts/角色冷却根.schema.json)；动作结束后仍须等待余下冷却，死亡不清，暂停/离线冻结。

闪避帧和几何在命中随机前检查，被无敌窗口避开的攻击不抽命中或反气功随机。已经支付的对方动作不退费用。起步体力100可连续支付的数量不等于可绕过动作/冷却连闪；体力最后一次付费后等待60世界步，从下一步每秒回10：每步累计10，除60取整数恢复并保留余数，最多补缺失；满量清余数，暂停/离线冻结等待和余数，死亡停止至明确复活。普通受伤不重开此等待，不能每帧自动补满或用界面时钟回复。唯一持久字段character.stamina_regeneration沿[两键schema](contracts/体力恢复状态.schema.json)与原persistent_state；正支付设等待60并保已有合法余数，零费/失败/重放不设等待。支付后第60步仅扣至0，第61步开始恢复；新建等待0/余数0，四旧导入明确60/0，不因此补满当前体力。

## 5. 集成与验收

14属性/资源、20状态与怒气/血魔、22动作/初装均引用本合同，不维护另一套防御公式。攻击来源字段、作用域、快照/命中时取值及实际资源变化要能在面板或诊断中追溯。缺完整气功作用、怪物属性/上下文或技能类型的配置仍拒绝，不能因核心公式已定就做空技能。

D1检查命中差值/5%与99%边界、严格小于概率、单值区间不抽随机、暴击取整、防御0/100与PvE加值只计一次、护盾/障力先后及0伤害、周期不重复防御和派生触发、致命归属/同帧重复、闪避首末窗口与距离算例。P/T再测Godot实际碰撞、完整伤害/职业平衡、真实怪物与活动、多人顺序及保存故障；本页不是这些实测已通过。

修炼属性顺序由修炼之门合同`timed_buffs.stat_application`维护：非反馈普通防御锚先乘再参与防转生命，PvE防御不乘；派生生命/内力和最终攻击区间在18最终覆盖前乘一次，不反向反馈转换锚，不二次放大技能平量。当前资源提高上限不补满、下降合法截断。


[38级正邪回收任务](contracts/三十八级正邪回收任务.v1.json)：本人直接普攻/直接攻击武功根动作接受时快照永久奖励来源，含具名旧固定威力直接剑技。首饰追伤后、guard及普通防御前，主目标首次合格命中仅加13一次，不再乘暴击/段倍率；首段未中可由后续首次命中应用。两派完成同族最高13；副目标、伙伴、召唤物及派生伤害不另加，仍走罡气、保护、护盾和障力。

固定步结果排序由[原战斗owner的step_resolution](contracts/战斗命中与减伤.v1.json)维护：原ID用未经规范化UTF8字节序，序号按整数；普通根/周期同批排序，完成每笔完整结果再下一项，之后只一轮尸毒波。重复持久队列键拒绝，传输副本沿原决定重放，不再入队或抽样；保存存疑先停依赖游标。原即时/派生时点必须各owner明示，不能为排序补默认下一帧。
