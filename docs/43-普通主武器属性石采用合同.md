# 43 普通主武器属性石采用合同

[权威参数](contracts/普通主武器属性石.v1.json)覆盖447新普通主武器火/毒单槽及真实1～10阶段；8初始武器、2异常来源、英雄/剧情剑/防具/首饰均不在范围。伪造/未完成可用本加工为项目选择，身份不变。其他元素仍待，不据此删去来源功能。当前未实现、未校准、未注册服务。

## 共享定义与来源

显式共享已有火/毒元素池、两个材料唯一物品及属性字段schema，不复制参数。公开正文只确认火属性石、火毒与四神独立并存；每阶贡献、上限、费用/概率及失败保护均为本地方案。普通职业商店适配器独立设计：火石10000两、毒石15000两、每颗10g、堆99，不修改英雄商店资格。

火每真实阶攻击+5；毒每阶攻击武功平威力+8、命中rating+2，不因名字附灼烧、中毒或持续伤害。只有当前生效组贡献，基础/强化/合成分别计一次；普通攻击/治疗/纯状态不收武功平威力，不按命中百分比解释。八普通职业不应用卢风郎英雄气功翻倍。

## 加工与移除

刀剑笑同图可用、2.5米内；角色存活空闲脱战无挑战，武器在本人装备包，职业/等级/rank/路线满足定义（含40三项未选派例外），完整实例及原库存合法且无占用。

20条配方逐项登记。第n阶耗对应元素石n颗、1000×n²两，成功率依次100/95/90/85/80/70/60/50/40/30%。首阶仅空槽、必成不抽；非空仅同元素精确阶段升1，失败扣材料与钱但完整保留原元素/阶段/收据及其他成长。真实10阶拒绝继续，不从火14显示反推真实上限。

异元素石不能覆盖旧槽；换型先独立确认移除。移除100000两、必成无材料、不抽随机，全部元素贡献清除且不返石；空输入拒绝不扣费。移除只写显式null，不改变同实例其他合法字段。

## 字段和事务

属性必须显式null或恰有element_id/stage/origin_receipt_id；stage严格整数1～10，不接受bool/float/string和stage0对象。来源收据须为同角色同武器血统普通属性加工成功结果，元素和阶段匹配；失败/英雄收据不能代替。缺字段或未知状态拒绝，不补空、不裁剪。

房主先查命令收据，再核修订、完整实例、资源及原库存合法；副本扣费/材料并检查最终格重，复制RNG后至多抽一次，字段/资源/RNG/修订/收据原子提交。重复同命令只返旧收据，保存失败仅重存。已接受攻击快照不被之后升阶或移除改写。

合法强化/合成及其他成长精确保留，临时强化或元素显示提升非空时拒绝加工；未知或无schema状态不清除修复。完整普通schema、其他元素/成长、其他强化贡献、反气功/显示提升、世界服务注册与经济联审仍待，当前不激活运行。
