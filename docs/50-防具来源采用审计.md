# 50 防具来源采用审计

[逐行审计](reference/防具来源采用审计.json)覆盖参数表14～35全部22表、1423行，含普通、英雄、武勋、通用及门派。每行有来源指针/SHA及待采用原因；候选ID不是正式物品ID，资料覆盖不代表运行或D1完成。

纯数字防御值精确保留，0单独计为明确零；复合防御token不截取前值或把括号数字加算，parsed_integer_defense明确为空。缺独立等级列的条目不从名称补成运行门槛。武勋及门派不能套普通装备资格。

衣服、靴、护手、内甲等混于来源表，现已在逐行审计中显式采用槽位，并以 `slot_adoption_segments` 记录表号及含端点的零基行号分段。采用结果为衣服813、靴246、护手235、内甲108、门派战甲21，共1423行。槽位依据为逐行内容核对后的项目采用；表35另有明确装备类别列，不把整表统一设为body。

槽位遵循[装备组合同](contracts/装备组与宝珠.v1.json)：护手类别可放入 `glove_a` 或 `glove_b` 之一，同一实例不能占两槽；门派战甲采用 `sect_uniform`，其资格谓词由54合同采用，组织状态接入仍待。甄凤柏武勋表28的衣服与内甲分别采用0～11行及12～23行，不按名称中的“甲”字合并。乐师表26末尾169～172行为武勋衣服。

初始见习短衫是项目1级防御2，不能与官网10级职业衣服混为一物。高强化复合图与目录基础值差异须具名裁定，不从显示总值减强化行生成通用基础表。

`high_enhancement_reconciliation` 已逐组对照2026图示20个防具样例：6组可定位纯整数基础但可见项小计不能复现截图、2组定位到复合基础token、12组无精确资格匹配来源。护手图的 `glove` 显式映射本审计 `gloves` 类别，不把鞋一并当同一来源物品。

6组数值差异为：男正普通神海战袍基础400、神皇战袍基础492，分别加图示强化550/650与四合80后，比截图高105；男正真神皇战袍基础499，加图示强化609/717与四合80后，比截图高112。男正真神海战袍的407（45）仍不截取。差额只作诊断，不直接解释为火、罡气、进化或强化公式；51既定整数基础暂不改写。护手/内甲无匹配来源也不能借相近名称或甄凤柏武勋条目补身份。

职业已按具名来源表采用，武勋列不会生成“武勋职业”；表35全职业条目显式采用现有14职业。全部1423行最低等级现已写定：来源独立数值等级1362行，表35职业列明确140级的9行，另有项目补全的甄凤柏武勋48行及乐师武勋4行；原57行缺独立等级列标记保留，不改成来源已公开。

106行武勋防具的资格由审计内 `merit_armor_eligibility_adoption` 采用。来源[武勋阶段](http://rxjh.17game.com/data/zb/202309/67905.htm)只支持60万/120万/150万/500万阶段下限，不证明这些装备的穿戴条件。项目明确采用：六普通职业54行保源80级、完成四转、武勋至少120万；乐师4行保源三转、另定项目60级及120万武勋。甄凤柏四类各12行按具名序列采用110/120/130/130/140/140/150/150/160/160/170/170级、六至十二转，110/120级60万、130/140级120万、150/160级150万、170级500万。真/普通同门槛，不按防御值推等级。

武勋是拥有量条件，穿戴不消费；不把武勋首饰的称号豁免扩到这些防具。武勋下降后保留实例/位置但资格失效不贡献，重新满足完整资格后恢复贡献，不补资源、不自动销毁或塞包。现有六转试练250武勋/胜不变，高门槛取得节奏和经济平衡仍须完成活动设计并实测，不能把资格设计当可玩性已验证。

1296行非武勋、非门派防具已采用独立的项目转职门槛表：最低等级1～9对应0转、10～34一转、35～59二转、60～79三转、80～99四转、100～109五转，110起每10级对应六至十二转，170～180为十二转。此表为项目决定，不把源等级列当官网转职证据；运行时读取逐行写定的条件，不从名称或角色等级生成转职。110级装备要求六转时，仍须115级实际完成六转才可穿，不降低晋级条件或改源等级。普通防具1296行资格已完整采用，加106行武勋及21行门派共1423行资格谓词已采用；门派组织状态接入仍待，资格设计不代表基础数值、正式物品或成长已完成。

来源直接支持1286行路线及830行性别。项目现已逐行采用全部1423行路线和性别：英雄缺路线列的137行采用不限正邪；587行无性别标签条目中，三名固定性别英雄遵循[14创建合同](14-职业创建与成长采用合同.md)，其余明确采用两类体型均可穿，仍受角色自身创建限制。这些均标明项目依据，不回填为官网字段，也不允许运行时缺值补全。

枪客表20行53～55、73～75的路线列写女、名称写男，6行现按具名项目裁定采用独立女分组，展示名相应改女，保留原名/源SHA及冲突证据，不宣称官网更正。没有性别冲突的名称标签与独立字段交叉核对后采用，不能从“服”“裳”等字推断性别。路线 `unrestricted` 包含未选派，`righteous_or_evil` 只接受已选正邪；体型须匹配采用列表，不通过改变角色身份来穿戴。

当前特殊问题计数：复合防御73行、空防御4行、缺独立等级列57行、已映射非纯数等级4行、武勋106行、门派21行、明确零防御21行、性别来源冲突已项目裁定6行。韩飞官表29行49、60、75、86的空字符串已从复合值分类中移出，仍保留原token及空解析值，不补0。计数可重叠，不能相加当独立条目总数。

2026-11-14在线复核全部77条异常，覆盖官网装备介绍三页。页面声明gb2312，使用兼容GB18030严格解码；按名称、等级、防御末三格逐条匹配HTML表格，73条复合值和4条空单元格全部仍与归档一致。三页表头均为“防御力”，未见括号数值解释；因此排除本次归档漏读，未解除数值采用阻塞。审计内 `defense_anomaly_live_recheck` 保存页面响应SHA、大小及77条匹配结果，基础定义仍为1219件、77条阻塞。

参数表外还存在[新门派战正文](http://rxjh.17game.com/data/tsplay/202203/66255.htm)的七级门派战甲，已在审计的 `supplemental_armor_source_groups` 单独保存来源：正邪各有门主款和成员款，共4个名称，不计入1423来源行。源文明确组织等级7，门主款仅门主、成员款门主及成员均可穿，取得NPC为神武门正派传功长老/柳善提督府邪派烈焰天王。基础数值及完整物品条件仍缺，不借此套出4～6级战甲规则。

现有[门派进度合同](contracts/故事冒险门派进度.v1.json)的 `sect.rank` 是本地个人门派身份0～3，不是上述组织等级，不能直接用于战甲4～7级校验。组织等级、身份及升降级后装备处理须独立采用，当前不增加第二份同义个人身份状态。

[54门派防具资格](54-门派防具资格采用合同.md)已采用21条35级/二转、组织最低4/5/6级、门主/成员条件及失效处理；组织状态owner/存档接入仍待。后续继续唯一正式定义、完整成长、取得/经济及预算。梅柳真19行的独立障力原整数另存为来源属性，并由职业特殊资源合同显式采用为 `barrier_capacity_flat`（障力上限平加点数），不并入防御或内力。计算为最终内力上限×2后加生效衣服障力；切组/防具失效移除相应来源，上限改变清恢复余数、当前量只下裁不补量。正式物品仍须绑定来源SHA，审计候选不可直接装备。[51普通防具基础合同](51-普通防具基础定义.md)已建立1219件基础身份、77条基础值阻塞；[55武勋防具基础](55-武勋防具基础与成长接入.md)另建立106件正式基础身份，并接入52/53共享强化/合成及独立银价取得；其他成长与活动经济仍待，门派正式物品仍待。未新增商店或激活运行。
