## 1. 世界结构与可达性

## 2. NPC与怪物运行

107条名称/入口记录包括同名和装置，不能直接生成107个唯一人物。每条正式映射必须标明NPC实体、别名、场景交互装置或重复证据；两个论剑堂银阶公子记录不能按名字直接去重。服务提交检查实体ID、场景、存活/可交互、2.5米距离及任务状态。

198条怪物/称号记录逐条映射为怪物定义、变体、称号或待核，不能把“高手阶段”填成等级。正式怪物必须配置生命、攻击、命中、防御、速度、感知、追击、返回、技能、掉落和刷新；156条文字等级仅能证明等级字段，不证明其他属性。

普通可刷新怪物按项目规则死亡后120秒世界模拟时间刷新；暂停、菜单、离线不计时。首领、任务专属和活动怪物必须另设刷新/一次性规则，禁止继承普通120秒。刷新落点固定且有合法导航，无空位则保持待刷新并报告阻挡，不瞬移到玩家脚下。

AI阶段为待机/巡逻、追击、预警、攻击、恢复、脱战返回、死亡；死亡停止未命中动作。脱战恢复不能重复发经验/掉落。一次有效死亡先生成唯一结算事件，再推进经验、任务计数和掉落；同消息重放不重复结算。

## 3. 地狱火龙讨伐的单机方案

下列精确规则为**项目设计**，仅入口等级、原门票价格及已明确奖励沿用公开资料。官网原10～30人、每日1～23点、周5次在参考库保持原值。

| 项目 | 本地采用 |
| --- | --- |
| 入口 | 银币广场讨伐管理员；140级且四式 |
| 人数 | 玩家1名+NPC伙伴9名，共10名实际战斗单位 |
| 门票 | 玩家购票1亿两；NPC不持票、不代扣9亿，属于单机成本改编 |
| 次数 | 每累计完成5个有效尝试后重置为新一轮；无现实日历门槛，每轮不是每周 |
| 开放时间 | 随时进入；无联网授时、系统日期限制 |
| 时限 | 开战起20分钟世界模拟时间；暂停冻结 |
| 次数与门票提交 | 确认入场、场景成功加载且开战时一次扣票并占用一次；加载失败不扣 |
| 有效尝试 | 开战后胜利、全队失败、超时或主动放弃均算一次；死亡不返票 |
| 成功增益 | PvE攻击/防御各+100，持续2小时世界时间；重复胜利刷新剩余至2小时，不叠加 |
| 失败参与奖 | 5个冰魄水玉；须开战后至少60秒且玩家有有效伤害/机制贡献，防入场即退领奖 |

五次一轮用于本地统计，不制造等待时间或额外免费门票。每次仍需实际购票；轮次和尝试ID写入角色。NPC伙伴无独立玩家库存，所有队伍奖励只生成一份归玩家，贡献排名按实际伤害/机制事件计算，不随机编造。

NPC具有攻击、防护、治疗及机制分工；玩家可命令跟随、守点和分配机关。NPC必须实际移动、受伤、死亡和执行动作，不能把九名伙伴仅作人数计数。伙伴装备/属性、治疗频率和伤害数值仍待战斗合同确定，不依赖在线玩家。

## 4. 合作机制与掉落设计

绿色安全罩、红色爆炸预警、数字人数圈、四个数字如意珠均保留。人数圈计数存活实际单位，玩家和伙伴各计1；圈外、死亡或重复身份不计。人数错误产生真实全队伤害，不用扣一个虚拟分数代替。

项目规则：人数圈分配6秒，四个珠子分别要求3/5/7/9次有效普攻命中，时限12秒；单次攻击对同一珠只计一次，多段武功不刷普攻次数。每成功解除两次完整机制，触发首领10秒眩晕弱点；失败不增加成功计数。全部时间用世界时钟，暂停不偷跑。

绿色安全罩、红区形状/伤害、首领生命/技能时序、召唤部下和人数圈标记值仍需在正式遭遇配置定值，未定不得宣称讨伐已可执行。上述精确数字是项目方案，不声称官网原值。

成功基础掉落项目方案：讨伐证明20个、普通宝珠1颗，五类型等概率；失败不发这两项。对应物品ID由物品合同闭合，宝珠类型随机与奖励事务一起提交。额外装备/秘籍/经验/历练及贡献追加奖励待配置，不能因为基础奖励已定就漏掉官网其他奖励类别。

基础证明20个意味着10次成功可满足稀有制作200证明，不计分解/额外奖励；票价合计10亿两。此为成本核算，不证明经济平衡已经通过；收入、其他消耗与各职业通关耗时仍须联测。

## 5. 暂停、退出与保存

场景切换在旧场景仍有效时预检目标配置、入口与落点；成功后再提交传送及费用。失败保留原场景与资源，不传到未知位置。重进场景不重置已提交任务奖励。

普通现场掉落按现有规则不跨会话保存，退出前明确提示；任务进度和已领物品持续保存。活动保存尝试ID、入场提交、时限剩余、奖励结算事件及固定步逻辑快照。重新继续恢复保存时的实际战斗状态，不退回阶段开场、不重置生命或计数、不重新扣票、不退已消耗药品、不重发既结算奖励；具体实体/机制字段见[数据合同](05-数据与存档.md#41-计时与活动快照)。

主动放弃需确认并结算为失败，不能用返回菜单撤销开战。读取旧存档的手动回退属于本地档案能力，不承诺防篡改；当前保存链内不得因为退出/重入重复领同一次奖励。

## 6. 阶段门槛与计划验收

仍须交付：全部正式场景/双向出口图谱、107来源名称的实体映射、198怪物/称号采用决定、逐刷点/掉落/服务配置、全部特色活动单机规则，以及本页未定遭遇和伙伴数值。修炼之门、地下密路、世外武林、遗忘村庄等不能因先设计讨伐而移出完整范围。

计划检查全部任务路径无循环锁、门槛边界、回程、场景失败回滚；普通120秒刷新与暂停；首领去重；10单位真实站圈、四珠独立计数、弱点10秒；20分钟超时、退出继续、门票/次数/奖励一致；成功BUFF刷新和失败参与资格。14职业及正邪两线均需实际可玩证据，当前尚未执行。
