### 1.3 修炼之门四主题与36房间

[修炼之门JSON](contracts/修炼之门.v1.json)按已归档官网55886正文保留北海/南林/东陵/虎峡谷四主题，每主题九房，共36个稳定map_id。主题推荐等级分别60～105、80～115、100～125、110～135，原文明确其他等级也能进入；本地入口设1级0转、全部14职业/三条合法路线，不把推荐段推成房内怪物等级。

入口装置在泫勃郊野(24,0,12)，交互锚(24,0,10)、回程锚(24,0,6)；为项目南部安全广场位置，不按官网坐标比例复制，也不据“时空之门旁”生成另一项未配置活动。每房独立移动装置在(0,0,50)，交互锚(0,0,48)，抵达锚(0,0,44)，南端8米安全圈不回血/清冷却。装置按场景交互物呈现，不虚构来源清单未列的具名人物。

房间统一使用JSON中128×128米的明确地板/边界与四块14×14米障碍布局，主题负责雪地/丛林/山地/峡谷表现，四周及中央留可走道路。几何只维护一份，世界图谱各房`layout_owner`必须精确解析房间行和布局；未知指针拒绝，不读备用默认场景。每房独立命名空间，不能因为共用几何而共用怪物生命或现场物品。

图谱现在60场景、165锚、20NPC及37个修炼装置；连接表共83条记录，其中原46条为固定连接，新增37条为选择器，**不能把83当83条固定有向边**。入口选择四主题任一房，共36个目的地；房内选择本主题另外八房或明确离开，当前房选择拒绝，换主题先回入口。展开后新增360个有向选项（36入口+288换房+36离开），无需复制360份同规则配置。

切换免费，存活/脱战/无其他挑战且2.5米内显式交互，提交检查自身会话/位置、精确选项及目标资源/锚/碰撞。失败留原房，不选默认房；成功保留角色资源、队伍和world_id，不刷新任一房怪物/掉落/计时。LAN每个世界每个房间为一个共享公共现场，不按玩家生成满血私场；进房不要求私人尝试ID，也不允许队长强制移动未提交请求的队友。

房内死亡由[死亡保存合同](contracts/死亡与复活保存.v1.json)的条件字段`training_gate_choice`保存原房、真实死亡脚位置和朝向；默认返程锚为郊野入口。死亡页明确选“原地复活”或“返回泫勃”：原地选项必须在同世界、同房、原死亡位置通过导航/碰撞预检；被阻挡则保持死亡页，玩家仍可另选返回，不能自动挪到安全点。两者均采用普通复活资源恢复、无费用/无无敌，保持冷却和已领结果，不刷新怪物、不重领礼包/BUFF。保存或重连恢复同一死亡ID和两项选择，不因载入自动复活；普通野外死亡继续工棚流程。

无小地图；禁止土灵符储存/传送、至尊热血符及情侣/结婚戒传送，具体ID/动作由1.7映射。原版自由PK按项目PvE范围明确取消；这里的普通怪物不获得NPC武者对抗标签。空间/路由/死亡选择、定时BUFF、每日任务及1.6怪物/定时刷点已设计但未实现，完整服务道具系统和流程/经济校准仍待完成，不宣称修炼之门已可玩。

入口标记无实体阻挡、2.5米显式交互，要求该任务正处首领挑战、存活/非战斗/空闲/无其他活动，无银两/物品费、无时限、不带队员/NPC/灵兽。预检实例/首领/资源/返回锚，失败不传送；入场不补生命/药/冷却。当前三首领为野兽，不支持血雨恶魔；其另需的NPC武者活动仍须落实。

公共竹林challenge_gate保持实体关闭；合格角色从门外标记进入自己的实例，只有该实例打开该门碰撞，不用一人Q002状态改全房地形。Q004/Q005标记不放进首领碰撞体。进入不是自动完成任务/重置普通世界，不因走到返回锚又自动进场。

死亡或明确放弃结算失败且不退已用药，死亡按正常工棚复活，存活放弃回本入口保实际资源；新重试用新尝试/满血首领，而保存退出恢复旧尝试的原首领生命/动作/随机/效果，不重建新局。没有对应活动却指向个人场景仍是坏档。

合法首领死亡一次推进个人“目标完成待交付”，提交怪物经验/历练及死亡凭证。其固定物品变为同笔持久待领记录，战斗威胁结束后可显式整批领取，空间/重量不足完全不变；退出前明确可带待领奖励返回，后来在曹斌服务领取，不重发经验、不再刷一只首领。任务最终交付与待领物品分开，主线回报不删未领凭证；待领不算背包材料，不能提前升级/卖出。

该持久领取是个人首领的项目改动，防止一次性灵矿/药在保存退出时随普通现场消失；普通怪与采集仍真实地面掉落。领取成功产生物品/堆ID后标记已领，不能同时保留可重复领取的凭证。LAN用房主死亡/领奖日志与角色确认水位提交，其他角色不能读取本人的奖励或被同房首领已死状态阻断。

旧档已经回报/待回报的阶段只证明首领曾被打败，不证明还有未拾物品；导入不凭空补待领灵矿/药/经验或重刷首领，保留其实际库存。准确旧schema/实例凭证转换仍需后续迁移设计和测试，不能为了填新字段猜一笔奖励。

## 3. 地狱火龙讨伐的单机方案

下列精确规则为**项目设计**，仅入口等级、原门票价格及已明确奖励沿用公开资料。官网原10～30人、每日1～23点、周5次在参考库保持原值。

| 项目 | 本地采用 |
| --- | --- |
| 入口 | 银币广场讨伐管理员；140级且四式 |
| 人数 | 玩家1名+NPC伙伴9名，共10名实际战斗单位 |
| 门票 | 玩家购票1亿两；NPC不持票、不代扣9亿，属于单机成本改编 |
| 次数 | 每累计完成5个有效尝试后重置为新一轮；无现实日历门槛，每轮不是每周 |
| 开放时间 | 随时进入；无联网授时、系统日期限制 |
| 时限 | 开战起20分钟世界模拟时间；暂停冻结 |
| 次数与门票提交 | 确认入场、场景成功加载且开战时一次扣票并占用一次；加载失败不扣 |
| 有效尝试 | 开战后胜利、全队失败、超时或主动放弃均算一次；死亡不返票 |
| 成功增益 | PvE攻击/防御各+100，持续2小时世界时间；重复胜利刷新剩余至2小时，不叠加 |
| 失败参与奖 | 5个冰魄水玉；须开战后至少60秒且玩家有有效伤害/机制贡献，防入场即退领奖 |

五次一轮用于本地统计，不制造等待时间或额外免费门票。每次仍需实际购票；轮次和尝试ID写入角色。NPC伙伴无独立玩家库存，所有队伍奖励只生成一份归玩家，贡献排名按实际伤害/机制事件计算，不随机编造。

NPC具有攻击、防护、治疗及机制分工；玩家可命令跟随、守点和分配机关。NPC必须实际移动、受伤、死亡和执行动作，不能把九名伙伴仅作人数计数。伙伴装备/属性、治疗频率和伤害数值仍待战斗合同确定，不依赖在线玩家。

### 3.1 新增局域网讨伐

上述1玩家+9NPC及奖励全归玩家是离线方案。局域网允许10～30实际参战单位，真实玩家优先占位，可明确补NPC至所选人数；每名真实玩家均需140级/四式及一张1亿门票，NPC不扣票。开战前逐人确认，全部符合且场景加载成功后统一提交入场；不得只检查房主资格。

胜利时每个符合参与资格的真实玩家各得个人基础奖励20证明/1颗普通宝珠、对应BUFF，独立结算ID与随机结果；这是明确项目个人奖励方案，不把同一公共物品复制给多人。额外公共装备/秘籍仍为独立奖池，分配方式未定前阻止冻结，不能默认全归房主。失败参与奖按每名玩家各自60秒/实际贡献条件判断；NPC不领取物品。入场票/次数和重连日志按19及05合同，人数圈计数不把同一玩家与其镜像算两人。

失联10秒仍未恢复的玩家从本次讨伐移出并记退出失败，不返票；只可结算符合条件的参与奖，不能再领同次胜利奖。其他成员继续，失联角色不再计人数圈；10秒内恢复原实体和已受伤状态。具体120秒席位及持久结果补确认见[19断线规则](19-局域网组队聊天与多开.md#6-保存重连与断开)。

## 4. 合作机制与掉落设计

绿色安全罩、红色爆炸预警、数字人数圈、四个数字如意珠均保留。人数圈计数存活实际单位，玩家和伙伴各计1；圈外、死亡或重复身份不计。人数错误产生真实全队伤害，不用扣一个虚拟分数代替。

新版正文已明确地狱火龙**暴走伤害50000**，见[2026系统更新](reference/2026装备与关联系统更新.md)；仅作为暴走伤害输入，不能套所有普通攻击/技能。具体触发、减伤适用与伙伴应对须在遭遇配置闭合后验证，不以调低此数代替合作机制。

项目规则：人数圈分配6秒，四个珠子分别要求3/5/7/9次有效普攻命中，时限12秒；单次攻击对同一珠只计一次，多段武功不刷普攻次数。每成功解除两次完整机制，触发首领10秒眩晕弱点；失败不增加成功计数。全部时间用世界时钟，暂停不偷跑。

绿色安全罩、红区形状/伤害、首领生命/技能时序、召唤部下和人数圈标记值仍需在正式遭遇配置定值，未定不得宣称讨伐已可执行。上述精确数字是项目方案，不声称官网原值。

成功基础掉落项目方案：讨伐证明20个、普通宝珠1颗，五类型等概率；失败不发这两项。对应物品ID由物品合同闭合，宝珠类型随机与奖励事务一起提交。额外装备/秘籍/经验/历练及贡献追加奖励待配置，不能因为基础奖励已定就漏掉官网其他奖励类别。

基础证明20个意味着10次成功可满足稀有制作200证明，不计分解/额外奖励；票价合计10亿两。此为成本核算，不证明经济平衡已经通过；收入、其他消耗与各职业通关耗时仍须联测。

## 5. 暂停、退出与保存

场景切换在旧场景仍有效时预检目标配置、入口与落点；成功后再提交传送及费用。失败保留原场景与资源，不传到未知位置。重进场景不重置已提交任务奖励。

普通现场掉落按现有规则不跨会话保存，退出前明确提示；任务进度和已领物品持续保存。活动保存尝试ID、入场提交、时限剩余、奖励结算事件及固定步逻辑快照。重新继续恢复保存时的实际战斗状态，不退回阶段开场、不重置生命或计数、不重新扣票、不退已消耗药品、不重发既结算奖励；具体实体/机制字段见[数据合同](05-数据与存档.md#41-计时与活动快照)。

主动放弃需确认并结算为失败，不能用返回菜单撤销开战。读取旧存档的手动回退属于本地档案能力，不承诺防篡改；当前保存链内不得因为退出/重入重复领同一次奖励。
