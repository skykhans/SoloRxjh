# 55 武勋防具基础与成长接入

更新日期：2026-11-14。状态：基础及共享成长设计，未实现。唯一物品目录在[武勋防具基础定义.v1.json](contracts/武勋防具基础定义.v1.json)，覆盖50审计全部106条武勋来源：衣服40、靴24、护手24、内甲18。

## 身份、基础与资格

106条防御均为源独立整数，逐件采用原值。每件以职业及源SHA生成独立 `armor_merit_…` 身份，保留来源指针和原名；跨职业同名不合并，护手两个槽位仍只装同一实例一次。20件源名称明确真件，采用真标识，不按防御大小或武勋阶段推真件。

资格直接引用50审计逐行条件，不复制第二份等级、转职或武勋门槛。六普通职业54条、乐师4条、甄凤柏48条沿既定项目采用。武勋是拥有量，不因穿戴、加工或购买扣除；武勋首饰的称号豁免不适用于防具。

重量与权限明确采用51既有项目规则：衣服1500g、靴500g、单件护手300g、内甲1000g，独立实例不堆叠；角色绑定、可同角色仓储及确认丢弃，禁卖、交易、复购、直接使用和分解。

## 共享强化与合成

本目录明确接入[52强化](52-普通防具强化采用合同.md)和[53合成](53-普通防具合成采用合同.md)的同一规则。两服务唯一资格目录改为51的1219件与55的106件之精确并集，共1325件，不以武勋标记或名称开放其他物品。

武勋件强化0～15，沿52项目曲线、真件系数、材料、银费、失败保留及原子收据规则。六个图示覆盖继续只命中原普通目录精确物品ID；武勋件不因同名或同级借用截图覆盖。衣服强化14/15的罡气输入仍限本实例基础、真实强化及合成防御。

衣服、靴和护手各4个合成槽，内甲2槽；沿53唯一属性池、寒玉石、逐槽概率/费用及同血统成功凭证，不另建武勋合成材料或配方。加工前须满足当前武勋等全部穿戴条件，武勋下降后不能继续加工。

[56觉醒与四神](56-普通防具觉醒与四神采用合同.md)另按衣服/最低五转采用明确分区，不扩给靴/护手/内甲；[57奇玉与进化](57-普通防具奇玉与进化采用合同.md)按四转/五转对四部位分区；[58属性石](58-普通防具属性石采用合同.md)已采用火/毒；[59转移](59-普通防具强化转移采用合同.md)仅开放具名双实例配方；[60提真](60-普通防具提真采用合同.md)采用精确普通→真同血统替换。[61防具附加提升](61-普通防具附加提升采用合同.md)另采用天池神丹分区；其他元素、其他药品/元素显示及完整档案/实例收据schema尚未闭合，不能据这些规则创建缺字段实例。服务仍未注册。

## 取得与失效

计划由泫勃银娇龙提供独立武勋防具目录，项目银价为 `100×最低等级²＋20×来源防御`。购买1～99件均逐件生成独立实例。购买须满足全部穿戴条件，不开放预购；报价及房主提交时重验资格、角色/NPC/会话/目录版本和修订，再核对随身银两、最终格数及重量。失败不扣费、不造物。

成功一次扣银两、生成唯一实例/血统/绑定与明确成长字段、写修订及收据。重复命令返回原结果；同命令异参数拒绝。保存失败只重存已提交结果，不再次扣钱或造物。购买不扣武勋，不额外发称号或奖励。

资格失效保留实例和位置，移除全部贡献；两组均重验，目标组含失效物品时整次切换拒绝。恢复资格不补资源、不复活、不刷新冷却。现有250武勋/胜保持原采用，60万至500万门槛的获取节奏及银两经济仍待完整活动设计和实测。

本轮完成基础目录和两项共享成长接入设计，未增加世界服务、未执行游戏运行测试。后续须覆盖武勋门槛前一值/等于门槛、报价后武勋下降、称号无豁免、买多件格重与保存失败、加工/装备失效及LAN权威重验。
