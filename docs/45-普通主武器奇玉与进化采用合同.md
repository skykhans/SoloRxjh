# 45 普通主武器奇玉与进化采用合同

[权威参数](contracts/普通主武器奇玉与进化.v1.json)登记447新普通武器字段：最低rank≥4的308件可奇玉，其余137仅空；最低rank≥5的264件可进化，其余181仅0。8初始武器和2异常来源不进入服务。真/伪造/未完成均按同一门槛分区，不变身份。

## 资格、材料与项目采用

刀剑笑同图可用、2.5米内，角色存活空闲脱战无挑战、已选派；奇玉最低80级/rank4，进化最低100级/rank5，另须符合武器职业/等级/rank/路线。武器在本人装备包，完整schema及原库存合法，无占用。

来源只证明奇玉独立、进化Lv1/Lv2存在及普通转移兼容要求。单槽属性、门槛、加工材料/概率/成本/失败保留和贡献为明确项目采用。共享现有奇玉池与进化tier总贡献唯一owner；4件普通专用项目材料另有明确身份，不接受英雄专用石替代，复用开发占位图。三奇玉攻击/武功/命中材料价100万/150万/80万，进化石200万，均10g、堆99、角色绑定；商店适配器尚未注册。

## 奇玉与进化结果

奇玉单槽攻击12、攻击武功平威力30或命中rating20。每次相应石1+20万两，80%成功，空槽或不同属性可赋予；成功替换旧玉无返还，失败扣成本并完整保留原槽。同属性拒绝不扣。移除10万必成、不抽随机、不返材料，空输入拒绝。

进化0到1耗普通进化石1+500万两，60%；1到2耗石2+1000万两，40%。成功升一tier，失败扣成本但不毁/不降。当前tier贡献总值分别攻击两界20/50、攻击武功平威力40/100；tier2替代tier1，不累加两阶。没有tier3或降级/移除/返石服务。

两来源分别计一次，仅当前生效武器，备用/包/仓不叠；武功只限根攻击武功、同域百分比及phase前，普通攻击/治疗/状态/衍生额外命中不复制。命中为rating平值，不加气功/反气功或生命内力，不按属性石翻倍。

## 严格字段与事务

jade_attributes必须0～1条数组，非空为property_id/value/origin_receipt_id，精确固定值及同角色同血统普通成功收据；evolution_tier严格整数0～2，各升级成功历史可核对。数值拒绝bool/float/string，缺字段/越界/低阶非法正状态/坏收据拒绝，不补空、不清零、不裁剪。

房主先查命令收据后校验资格/schema/原库存及修订，副本扣资源并检最终格重，复制RNG后至多一次开奖，字段/成本/RNG/修订/收据原子提交。重复返旧结果，保存失败只重存；未知或非空临时显示提升拒绝加工，不洗掉旧成长。普通两实例强化转移与提真尚未采用，不套英雄全字段保留或复制来源奇玉。

完整普通schema、其他元素/强化其余贡献/反气功/显示提升、普通转移提真、世界服务注册与经济联审仍待，当前不激活运行，D1尚未完成。
