# 54 门派防具资格采用合同

更新日期：2026-11-15。状态：项目资格设计，未实现。唯一结构化规则在[门派防具资格.v1.json](contracts/门派防具资格.v1.json)。覆盖[50审计](50-防具来源采用审计.md)中21条四至六级门派战甲，每级7条，保留各自职业、来源等级35及明确防御0；不合并成普通衣服。

## 来源与项目决定

来源名称明确四、五、六级，项目采用为组织最低等级，高级组织允许穿低级战甲。角色须至少35级、实际完成二转，并满足逐行职业、路线和体型条件。门主和成员均可穿。这些组织比较、角色范围和二转条件是项目选择，不能写成官网已公开细则。

[七级门派来源](reference/官网资料/目录正文.json)的records/18明确组织七级、门主款仅门主、成员款门主和成员均可穿，正邪各两款。四款仍是表外来源组，基础数值、角色等级和完整正式物品条件未定；不把七级说明当作四至六级官网证据。

## 权威资格接口

检查必须同时读取当前组织与当前角色成员关系。组织须存在且未解散，等级为1～7严格整数；成员须有效，角色ID与操作角色一致，组织ID与所读组织一致，身份为门主或成员。禁止使用别的组织等级或别人的门主身份。事务提交前复核双方修订，发生变化则拒绝本次提交并重新报价。

本合同只定义读取接口，严格结构见[门派资格输入schema](contracts/门派防具资格输入.schema.json)，不创建第二份持久化成员状态。organization仅接受null或organization_id/level1～7/revision三键；membership仅接受null或character_id/organization_id/role/revision四键。任一null都不具资格，源组织未解散与成员有效必须由实际owner验证，不能因投影无有效标记就默认有效。完整源先校验，再读取此接口；不能通过投影丢弃坏源字段。旧 `retained_story_adventure.sect.rank` 是琉璃剑宗个人故事身份0～3，不能转成组织等级或门主身份；旧档不得因此自动获得四级组织。组织与成员关系的唯一状态owner、存档迁移、组织升级/降级和完整门派玩法仍待接入，当前不启用穿戴或取得服务。LAN预览不能替代房主重读权威状态；membership角色与组织ID分别核实际操作者和同一组织。提交时组织修订各自等原组织修订，成员修订各自等原成员修订；两修订数值不必互相相等，任一个改变均拒绝并重新预览。保留02本地NPC组织范围，不由此新增玩家邀请或在线公会。

战甲不绑定发放时的组织ID，穿戴按当前实际所属组织检查；这条规则不改变物品交易权限。21条资格谓词已确定，只代表设计条件闭合，不代表组织状态、正式物品或门派功能已完成。

## 资格失效与恢复

退出、被移出、解散、组织降级或其他穿戴条件失效时，两组均重新检查。实例保留原位置与血统并显示失效原因；失效实例不贡献属性、外观或套装来源。身份变化与投影在同一权威提交中生效，加载和LAN加入先检查再投影。

当前资源只按新上限下裁，恢复资格不补生命、内力、障力或复活，不刷新冷却。切组仍遵循13合同：目标组含失效非空槽则整次拒绝。卸下允许进行，但必须通过最终背包格数和重量校验。

21条防御0是源明确零值，不补普通防具防御，不套51/52成长。正式物品、重量、权限、强化与取得仍须独立采用，世界服务未增加。

## 后续验收

实现时逐条覆盖等级34/35、转职1/2、组织门槛前一档/等于/高一档；无组织、退出、错误组织/角色、伪造门主、非法等级类型、陈旧修订均须拒绝。覆盖装备中降级/退会、非生效组失效后切组、满包卸下、恢复资格不补资源、保存失败及LAN权威重检。本轮仅检查来源映射、规则与引用，不当作实际运行通过。

读取组件67结构用例通过，21条来源各级7条的0防御/35级/二转映射通过。跨组织拼接即使结构合法仍必须语义拒绝；上述检查不证明完整组织/成员授权或实际换装通过，完整状态owner及正式物品门槛保持。
