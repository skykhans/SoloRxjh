## 英雄独立任务

原页明确韩飞官、谭花灵，不能当作六英雄完整表：

- 谭花灵：泫勃派刀剑笑，伏魔花灵剑/真款专属强化转移任务。
- 韩飞官：火龙深渊地狱火龙，火龙刀/真款专属强化转移任务。
- 先完成升天四式，背包须有火龙伏魔强化符；不得用普通符代替。原页写全部属性转移，但和普通排除表的精确关系需分操作核实。

专属武器晋阶、角色四式和强化转移是不同进度，不按角色到140级自动完成全部任务。旧NPC入口是否被新版本改动仍须核对，不复制六式司空揽杰覆盖旧来源。
