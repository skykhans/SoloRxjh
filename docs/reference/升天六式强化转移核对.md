# 升天六式强化转移核对

核对日期：2026-11-13。官网[67857目录入口](http://rxjh.17game.com/data/zb/202309/67857.htm)跳转到[2023转移专题](http://rxjh.17game.com/event/2023/a20230907Transfer_props/)。已读普通转移、英雄火龙转移、[FAQ](http://rxjh.17game.com/event/2023/a20230907Transfer_props/faq.html)三页，实际查看三张背景图及原尺寸注意事项。18组FAQ原文、来源哈希与结构化规则见[参数JSON](升天六式强化转移规则.json)。不是最新客户端实测。

## 1. 普通武器/防具转移

| 内容 | 已核公开规则 |
| --- | --- |
| 道具 | 强化转移符〔武器〕（升天6）、强化转移符〔防具〕（升天6），右键打开 |
| 装备档 | 150级来源→160级目标，不据此扩大为任意低级转任意高级 |
| 成功率 | 100%；不是普通强化概率 |
| 来源强化 | 11及以上，最高转移15；目标可以是0或更高 |
| 强化结果 | 用来源覆盖目标，不取两者最大值；150级+11与160级+15转移后为160级+11 |
| 转移字段 | 来源强化、属性石效果覆盖目标对应字段 |
| 不转移字段 | 来源合成、奇玉石、觉醒；目标原合成/奇玉石/觉醒保持 |
| 目标合成 | 内甲2手，其他部位4手；要求的是接收装备，不把来源合成复制过去 |
| 兼容 | 同职业武器、同进化等级；普通对普通、提真对提真、武勋对武勋；示例还标同势力、同品级 |
| 原件与锁定 | 来源装备消失，目标不新增锁定；不能保留来源再重复提取 |
| 商城参考 | 武器符/防具符原图各10000元宝；不是项目手续费或已确认本地获取方案 |

觉醒阶段可以不同，转移不覆盖目标阶段。两件装备都含奇玉石不妨碍使用，但不将来源奇玉转过去。武器不能转防具，不同职业武器不能互转；具体防具部位兼容矩阵仍需逐定义明确，不能只验“都是防具”就放行。

## 2. 英雄专属转移与武器晋阶分开

英雄使用火龙伏魔强化符（升天5、6），在司空揽杰处接本职业专属强化转移任务，150级英雄专属武器转到160级；原图价格10000元宝。不能调用普通武器符入口，也不显示其他职业的任务。

英雄页明确“全部属性转移”“不会降低原有强化等级，并且所有属性全部保留”。另强调普通专属武器转职提升任务需天世宝血珠并会降低强化，该任务与强化转移不同；不能将通常武器晋阶的降1级套到使用此符的任务。

但通用FAQ同时写合成/觉醒/奇玉不转，且FAQ列举了英雄符。本页保留这处范围不明：英雄专页的全部属性与FAQ排除字段是否构成特例，仍需专项任务/新版说明核对。不能自行按“全部”复制所有未知字段，也不能无说明套用普通排除表。英雄任务的中间物品、源/目标实际消耗及保留方式逐任务再确认。

## 3. 采用与事务要求

项目正式操作需区分普通转移、英雄专属转移、专属武器晋阶，先选明确操作类型和配方版本，再检查两个不同实例、等级/职业/势力/品类/进化/合成、来源真实强化及道具。

普通方案应保留目标实例身份和原有非转移字段，只消费来源并覆盖允许字段；这是项目实例处理方案，不宣称官网使用相同内部ID。目标强化更高时明确预览降级，用户确认才提交；不自动拒绝合法降级，也不暗改为保留最高值。

材料取得、额外银两、道具使用数量、15+[n]处理及英雄字段冲突未闭合，当前不生成正式可执行配方。费用未知不默认为0，100%成功不代表材料/目标资格检查可以省略。

LAN由房主提交来源消费、目标变更、道具费用及结算ID，取消/失败不动任一实例；保存/重试按05/19协议去重。角色参数中心允许直接配置，但不把自由配置结果当此任务已正常完成。

## 4. 计划验收与范围

测试来源+10拒绝/+11接受、+15上限、来源+11覆盖目标+15与来源+15覆盖目标0、150→160档位、内甲2手/其他4手、进化/职业/势力/品类不匹配、觉醒不同仍可用、奇玉保留、源实例消失和目标不锁。

另测英雄入口、本职业任务可见、晋阶/转移不混用、字段冲突在设计冻结前解决；重复确认、取消、满包、断线、双方保存失败不复制原件或重复扣符。
