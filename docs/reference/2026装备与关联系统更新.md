## 1. 高强化与成长道具

武器强化14/15提升攻击力、武功攻击力；衣服、护手/鞋提升防御力、生命力，鞋与护手增加属性相同。160/170级、普通/提真及强化14/15分别展示，不能压成统一倍率。内甲亦有独立展示。

正文明确已强化15的装备可使用天池神丹、碧绿神草、灵脂仙草等提升强化等级，效果在本次优化内。**这些不是“永久真实强化绝不超过15”的证据**：需要核实道具提升的实际/临时性质与宝珠是否计入，不能直接将显示强化作为宝珠公式输入，也不能因为13合同公式仅支持0～15就删除高强化相关道具。

各图中的精确属性尚未逐图识读，本页不补出加成公式、失败率或强化上限。首饰名匠符、武勋首饰、守护及转移符其他目录页多为图示，另需逐页核对，标题读取不能判作完整。

## 4. 合心比武台不能漏掉的细则

130级/三式及以上、武勋非负、善恶值非负等条件；原页要求转职等级一致，具体匹配口径仍须解释后落地。原开放每日20:30，单机时间改造另列。入场选5种NPC之一，选择10秒，超时随机；NPC气功有三种概率档，精确概率正文未列。

NPC每5秒解除自身debuff，南林野兽王另有免疫。原规则NPC与角色不能互相提供增益，不能套用讨伐治疗伙伴方案。NPC能力随角色属性变化，原表100/90/120等数字的单位需核实，不擅自当固定攻击值或百分比。

进入5秒开赛，战斗5分钟；NPC每次死亡5秒后复活，第5次死亡后不再复活。角色有4次复活机会，未手选时5秒后场中复活。角色与NPC死亡/剩余复活分别计数，不能角色首次倒地直接结束。双方角色及NPC各击杀5次获胜；超时按击杀次数，再按点数判定，点数完全相同处理仍待明确。

禁止变身道具、潜行、回城/婚戒等移动物及龙飞行；允许灵宠，其debuff和NPC免疫实际作用。胜10/负2比武印章；兑换随机经验/武勋/武皇通币，五/六式角色不获经验奖励，其他阶段不得自行类推。概率及奖励量待定，服务器故障补偿不直接套用本地退出。
