# 官网目录覆盖与单机化决策

更新日期：2026-11-13。范围为已读取的官网公开主目录123个文章链接及4个披风补充链接，共127个来源；完整快照见[来源索引](官网来源索引.json)。V25专题/补丁和装饰全目录是另外的版本证据及扩展，不能把127页说成官网所有历史网页。

## 1. 采用原则

2026-11-13用户追加至少LAN与多开：本矩阵的“本地/NPC适配”表示离线必须可玩，不排除真实玩家参与局域网；组队经验、队内/世界聊天及联网权威规则见[19合同](../19-局域网组队聊天与多开.md)。账号大区/转服/付费线路仍不采用，不能据旧“单机”文字移除LAN。

用户要求完整参考端游至升天七式，同时明确为单机。职业、成长、装备、技能、物品、地图、NPC、任务、怪物及战斗机制完整覆盖；网络参与方式改为本地NPC/AI活动。纯账号服务器、大区、转服、VIP线路和充值基础设施不实现。

单机化并非给窗口改个标签：需要真正运行敌我NPC、目标、前置、计分、奖励、失败和存档，不制造假在线玩家或只展示不可用入口。每个参数的改动要保留官网原值、项目值、理由与测试，不能默默改掉。

## 3. 关联系统不得遗漏

| 系统 | 已核对的参考机制 | 单机设计与核验要求 |
| --- | --- | --- |
| 师徒 | 徒弟一转、师傅二转、贡献阶段/授业、关联任务与奖励；原页跨职业规则有冲突 | NPC导师/学徒关系；传授、贡献、解除、奖励真实生效；新版本限制先核实 |
| 灵兽/骑乘 | 15/50/75/100/125级对应转职、特殊效果、食物/鞍、骑乘/飞行及限制 | 本地伙伴成长、召唤/互斥、战斗与装备；不能只做跟随外观 |
| 灵兽特殊效果 | 15级学习；无视防御、出血、狂暴等；角色死亡时不发动 | 独立概率与事件去重，灵兽出血不能混成刺客同一状态 |
| 制造/锻造 | 材料加工、武器/防具升级、可锻造替代武器等 | 配方、条件、成本、成品容量和实例来源；不能先扣料再发现放不下 |
| 进化/觉醒/提真/加工 | 与强化、合成并列的装备成长，不是统一稀有度 | 分别建立前置/材料/成功失败/继承规则；缺资料不以倍率补默认 |
| 物品与重量/仓储 | 堆叠、绑定、交易、空间、重量和新版复购限制 | 完整本地经济事务，不依赖在线玩家交易；容量与重量分别核对 |
| 情侣/关系/婚礼 | 关系等级、单戒/对戒/婚戒、场地票与礼服、仪式确认及技能 | NPC关系任务与仪式；获取渠道本地化，不能默认把现有主线NPC当关系对象 |
| 排名/名声/武勋 | 原官网有等级、门派、武勋及战场积分等 | 参考体系完整记入；本地记录与NPC声望，不显示伪全服榜 |
| 变装/发型/名称/装饰槽 | 披风、其他衣饰、美发/整容/名称道具、翅膀新槽 | 独立类型与实际效果，披风目录中的非披风道具单列保留 |
| 区域计时/增益/副本 | 通行、修炼房间、疲劳/次数、死亡复活、地图限制和BUFF | 时间与存档/退出明确；现实付费时效不直接强加到单机；所有改动写差异 |
