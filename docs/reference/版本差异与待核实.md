## 3. 新版复购要点

只针对部分商品：60级及以上特定首饰；经过合成、强化、觉醒、属性赋予的装备（含进化/提真）；部分石头。不可交易、活动、任务取得、冰魄水玉购买等道具不支持。

退出、切换服务器、进角色选择、跳图会清空列表；单机不实现服务器操作，但其他会话边界要明确。购回应检查空间与重量，不能凭复购复制原实例。精确费用、列表容量等原文未列数值，保持待核。
