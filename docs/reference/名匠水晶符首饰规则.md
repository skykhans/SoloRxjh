## 2. 加工结果

成功提升1个加工等级，还有机会额外增加1～2级，即图文表达存在一次跨多级效果，不能沿用“每次最多+1”的统一首饰规则。

| 操作前加工等级 | 失败结果 |
| --- | --- |
| 6级及以上 | 降至5级，不是只掉1级 |
| 5级及以下 | 每次降低1级；0级失败的下限处理原图未写 |

加工失败保护首饰不消失。“加工等级”不能改名为武器强化等级或套用武器强化失败销毁。符、材料、费用的扣除时点/数量和完整成功率仍待核，不能因首饰不消失就退还全部材料。
