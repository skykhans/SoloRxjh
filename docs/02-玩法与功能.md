# 玩法与功能

更新日期：2026-11-13。目标为单机游戏，系统整体参考《热血江湖》，使用 Godot 4.7.2 / GDScript。本文定义功能与事务，[数值与物品目录](12-数值与物品目录.md)定义唯一数值与系列，[官网参考资料](11-官网参考资料.md)记录出处。

全部内容是目标规格。现有 Rust 版具备的功能、历史结果和新增缺口集中于[实施与验证记录](09-实施与验证记录.md)；没有 Godot 实现或测试记录的内容不能标为已完成。

## 1. 完整游玩循环

本地登录 → 创建/选择角色 → 接受教学与任务 → 探索、战斗和采集 → 升级/积累历练 → 拾取材料与装备 → NPC买卖、仓储、强化、合成与制造 → 学习武学/气功、职业晋级与门派成长 → 挑战新区域和首领 → 保存并再次继续。

所有面板读取同一份角色和会话状态，按钮必须连接实际规则。门派、商店、消息、掉落、怪物和奖励都在本地运行。游戏可随时暂停，退出世界会清理现场。

## 2. 本地登录、档案与角色

启动先校验版本、配置和资源，再进入本地档案界面。档案表示本机游玩身份，不使用账号密码、服务器认证、充值或网络连接。

- 支持最多3个本地档案，每档案最多6个角色；档案名2～16字，角色名2～12字，去除首尾空白，拒绝空白、控制字符和同档案重名。
- 登录界面提供档案选择/创建、设置、退出；角色界面提供创建、选择、继续、删除和返回。
- 创建角色选择姓名、已核对职业之一、两类体型、肤色、发型与服饰配色；预览可旋转、缩放，最终确认才写文件。
- 选择页展示姓名、职业、等级、晋级/路线、地图、最近保存时间、当前装备与披风；继续失败显示具体文件和原因。
- 方尘为默认剑客预设，允许自建身份；与原著的衔接见[项目与故事](01-项目与故事.md)。其他职业须使用相符武器与技能。
- 删除先显示角色完整身份并要求输入角色名确认；取消不写文件。新建角色失败不得产生半份存档，切换角色不得沿用上一角色的装备、消息、镜头或战斗状态。

旧 `save.json` 通过明确的导入入口读取和预览，成功后生成独立角色，不覆盖或移动原文件。

## 3. 职业、成长与晋级

具体单机采用方案见[14职业创建与成长合同](14-职业创建与成长采用合同.md)：本项目选择全部职业直接创建并从1级0转开始，乐师与英雄职业低阶内容作为明确改编补全。这不是官网统一起点；历史资料仍保留原值。全部初始属性、经验与完整能力参数未闭合前不冻结该合同。

逐职业配置创建资格与起始等级、名声/晋级、点数、装备和教程状态，不能把本项目1级0转方案冒充官网统一规则。已读的V8乐师有特殊解锁/起点/四转链，当前官方是否保留仍待核，见[历史证据](reference/职业创建差异与历史证据.md)。创建资格、角色初始化、角色晋级和武器晋阶分别结算，不能用等级直接推导已经完成哪些任务。

刀客、剑客、枪客、医师、弓手、刺客、乐师、格斗家各有实际武器、攻击距离、动作、技能与被动气功。医师、乐师也能独立完成所有主线，不依赖其他玩家补足输出。

角色经验、历练、修行点、气功点、银两、贡献分开记录。等级由累计经验推导，不能另存一个不一致的等级值。升级立即刷新属性和面板；满级不妨碍正常掉落与任务。

完整覆盖一转至十二转（升天七式）。一至五转为普通晋级，六至十二转分别对应升天一至七式；官网已核实六转115级、七转120级、十一转160级、十二转170级，其他门槛与分阶段任务正在逐项校对，不把装备可用等级、任务接取等级和最终晋级条件混为一谈。每段通过本地NPC任务一次提交。职业晋级与宗门身份为两条独立进度；路线影响装备/武学条件，不开放PVP或在线阵营战。转职取消、条件不足、任务重复回报不得改变资源。

## 4. 属性、武功与气功

角色面板展示基础值、成长、装备、强化/合成、气功、门派和临时效果的来源，以及最终生命、内力、体力、攻击、防御、命中、回避、暴击和武功效果。穿脱、升级、学习或晋升后所有面板立即一致。

武功库覆盖对应职业全部已核对的普通/升天武功，四个快捷槽只是当前装备数量，不是职业技能总量。普通气功、升天气功和反气功分别建模，并覆盖秘籍、天机石、升天历练与升天点数。

主动武功先检查职业、晋级、路线、等级、修行点、历练、银两和前置；学习与升级一次提交。施法先检查存活、武器、动作、目标、资源与冷却，再一次扣费，按固定步命中时点结算。不能靠动画事件发放伤害。

被动气功单独分配点数，进入统一属性与触发规则；实际等级和装备提供的有效等级分开显示。洗点先完整预览将返还的点数，不返还历史学费，不复制气功加成。

## 5. 移动、镜头与输入

| 输入 | 功能 |
| --- | --- |
| WASD / Shift | 相对镜头移动 / 奔跑 |
| 左键地面 | A*寻路，显示目标与不可达原因 |
| 左键敌人 / 采集点 | 选目标并接近，进入有效距离后按意图执行 |
| 右键拖动 / 滚轮 | 环绕镜头 / 缩放 |
| J / Q / R / G / V | 普攻 / 四个已装备武功快捷槽 |
| Space / Tab | 闪避 / 锁定或切换 |
| E / F | 最近对象交互 / 最近掉落拾取 |
| 1 / 2 / 3 | 生命药 / 内力药 / 归还符 |
| B / C / K / T | 背包 / 属性装备 / 武学气功 / 任务与修行记录 |
| U / H / M / Enter | 铁匠 / 门派 / 地图 / 本地消息 |
| Esc / F3 | 关闭当前面板或暂停 / 开发碰撞显示 |

行走4m/s、奔跑6.5m/s，斜向归一化。圆形脚印连续碰撞与滑动，建筑、水域、竹干、围栏、关闭入口和边界阻挡，桥可通行。采集/寻路不能用传送替代；WASD、普攻、技能或闪避会取消自动移动。

镜头默认7m、3～12m范围、俯角15°～65°，检测遮挡收近。锁定12m内存活无遮挡目标，按距离/稳定ID切换；目标死亡、超过15m或连续遮挡1秒取消。锁定不扩大攻击范围。

## 6. 战斗、怪物与死亡

保留三段普攻、技能、体力/内力、闪避、药品、命中视线和防御减伤。近战按形状与朝向判定，远程有真实投射物/音波及遮挡；一次动作中每段只对同一目标结算一次。

每只怪物有独立出生点、类型、等级、生命、AI、掉落组、刷新及任务归属。待机/巡逻、感知、追击、预警、命中、恢复、脱战、返回、死亡和刷新互斥。不能穿墙、隔安全区伤人或死亡后继续攻击。

普通怪、精英、远程敌人和首领要有不同职责；高阶变体有独立配置和可辨认外观。首领预警须对应实际命中范围，主线首领本档只结算一次，可重复挑战使用独立记录。

死亡停止未结算动作，打开死亡页；返回工棚恢复资源，普通现场重建，保留成长、背包、装备、货币和主线，不扣银两。死亡当帧不保存零生命的活动角色。

## 7. 武器、装备与披风

武器按职业、等级档、晋级与路线形成系列，防具、内甲、护手、靴和首饰各有真实槽位与属性。每件装备独立实例，拥有定义ID、实例ID、强化、合成孔和来源；同名装备不堆叠、不互相共享强化。

穿戴先检查条件与槽位。替换时旧装备回到原行囊位置，因此满行囊仍可等量换装；卸下需要空格。不存在的定义、错误职业/路线、超等级和重复实例拒绝穿戴或读档。

主装备与辅助装备按[辅助装备资料与本地方案](reference/辅助装备与服务类道具.md)区分，备用组不直接叠加属性；当前生效组、预览组和装备所有权分别管理。切换条件、冷却和宝珠映射明确配置，不以空字段猜测。

宝珠按[官网讨伐与宝珠规则](reference/讨伐与宝珠规则.md)单独建模：140级及升天四式双条件，5类型/4品质、6个位置（护手2），单颗也有效，增益取角色转职与实际装备强化，不能用临时BUFF虚增。合法规则使资格暂不足时，保留原物而属性失效，符合后恢复；这不允许未知定义或重复实例绕过校验。

披风单独成系列：获取、背包、试穿、穿脱、属性合成、显隐、模型适配和保存均需完成。预览不提前提交，不共享其他角色的节点或实例。原有武器挂接缺陷纳入最终美术验证。

## 8. 物品、背包、仓库与快捷栏

物品分生命药、内力药、功能消耗品、普通/进阶材料、成长材料、任务物品及装备。每种定义明确堆叠、用途、条件、绑定、出售、丢弃、仓储和主线保护，不能仅填名称。

材料与装备容量分别管理，可由仓管扩容；仓库提供实际存取。每次移动检查源数量、目标容量和实例归属，全部成功才提交。整理保持物品数量、唯一ID和任务状态。

快捷栏绑定真实技能、药品和归还符，显示数量、内力不足、未学、冷却与不可用原因。空格不显示伪功能；UI点击与键盘使用同一条规则路径。归还符被攻击或取消时不扣物；传送落点也需配置和碰撞校验。

## 9. 掉落、拾取和采集

怪物首次死亡后一次结算经验、历练、任务计数和掉落。掉落有唯一ID、具体物品/实例、数量、位置及已结算标记；随机表与种子按数值文档执行，重复消息不再生成。

F拾取最近2m内无遮挡掉落，同距离按ID。整份入袋成功才删除地面实例与地图标记；失败保留并说明原因。多件拾取逐份提交，列出未拾取项，不吞掉满包物品。未拾取物保留至会话退出或死亡返回，不定时消失，不写角色存档。

6株可采玲珑竹按普攻范围/方向/遮挡命中，技能不采竹。非剑职业使用近身采集工具动作。装饰竹、空挥、隔墙、倒伏状态不给经验或材料；现场恢复与暂停规则保持一致。

## 10. NPC、商店、铁匠与制造

曹斌、铁匠、药师和仓管等服务有固定身份与位置。交互选择最近对象，同距离按稳定ID。所有服务提交时重新检查2.5m距离；远处快捷打开面板只允许查看。

NPC商店支持按数量买卖，显示单价、总价、容量和主线保留量。浮仙剑、任务文书、绑定物及不允许出售的披风不能被批量卖出。装备实例出售不返还强化材料。

铁匠完成强化、属性合成、洗炼、强化转移和制造。操作前列出来源/目标、费用、材料、成功率、成功与失败结果；取消不扣资源，确认后一次结算。缺料、溢出、重复请求和异常退出不能产生半份结果。

## 11. 任务、区域与门派

保留Q001报到/取剑/认主、Q002采竹交差、Q003竹林挑战、Q004云溪谷、Q005寒石古道；扩充晋级、披风、制造、仓储与高阶狩猎任务。任务面板展示前置、进度、奖励和方向，不能越序或重复领奖。

任务交付在副本中先扣需求、检查奖励容量和上限，全部成功一次提交。三类委托独立结算：工棚一次性委托、区域重复狩猎、宗门贡献委托；同类不能复用已领取批次。

琉璃剑宗提供身份、贡献、捐献、委托、兑换与晋升，并影响真实攻防。门派是本地NPC组织；不显示在线成员、玩家邀请或虚假的其他玩家交易。

## 12. 地图、消息与记录

世界保留320m见方的连续探索基线，并扩展等级分区。小地图北朝上，显示玩家位置/朝向、NPC、活动怪物、掉落、任务、区域边界、图例与名称提示。标记随出生、死亡、拾取与区域变化即时刷新。

320m与旧三地区只描述兼容基线，不限定完整地图数量或场景规模。按[地图NPC与怪物](reference/地图NPC与怪物.md)承接升级区、城镇、地宫、修炼房及高阶副本的职责；地图进入条件、推荐等级、任务阶段、角色晋级和物品等级分别判断，不能要求先拿到任务奖励才允许进入做任务的地图。

地图切换、入口NPC/装置、通行物、房间/难度、允许道具、死亡返回、刷新/次数和奖励按场景配置。官网不掉物的专门经验区不能套普通怪掉落；原文推荐等级不能当硬门槛。坐标和场景ID随存档保存，退出场景清理其临时状态。

世界地图展示道路、水域、服务、推荐等级和当前目标；区域入口可设路标，3m内自动清除，可手动清除。路标只是方向与距离，不是传送或自动路径。

本地消息分系统、战斗、NPC和本地记录，最多100条，支持筛选、折行、滚动与保持阅读位置。输入最多120字，支持中文IME；组合期间Enter只提交组合，下次Enter发送，退格交给输入法。输入不得触发战斗快捷键。

支持 `/帮助`、`/任务`、`/位置`、`/门派`、`/交谈`；NPC答复仍检查距离。消息、草稿、筛选和路标为会话数据，不持久化。

## 13. 暂停、设置、保存与清理

每次只打开一个模态面板；打开面板暂停世界、战斗、AI、冷却、刷新、移动、镜头与世界音源。必要UI继续响应；关闭恢复。Esc先关闭当前面板，确认页取消返回来源。

主音量、音乐/音效独立音量、镜头距离、分辨率、全屏/窗口、垂直同步与图形预设需实际生效并保存。未实现选项不得显示可用控件。开发调试开关不进入正式设置。

新角色、任务、升级、首领、拾取、买卖、仓储、强化/合成/制造、学习、气功及门派事务成功后自动保存。手动保存限安全区；没有周期性强制覆盖。保存失败保留旧文件和内存进度，退出时明确提示并确认。

返回选角/档案或退出后清理整个世界会话、临时节点、音源、输入、路径和消息；只保留已提交的角色进度。保存结构与故障处理见[数据与存档](05-数据与存档.md)。

## 14. 完成标准

除核心成长战斗外，[官网覆盖与单机化](reference/官网目录覆盖与单机化.md)逐项列出的灵兽/骑乘、变身、师徒、关系/仪式、竞技与势力挑战、讨伐、攻守据点等，需要保留对应系统职责并完成本地NPC适配。其具体规则仍处于D1资料/设计核验，不以“参考过”或“后续候选”代替内容承接。纯服务器、转服与付费线路不采用，依据是用户明确的单机定位。

每项功能都需要“入口 → 条件 → 规则 → 结果 → 反馈 → 保存/恢复 → 失败保持”完整链路。全部职业至少分别走通创建、战斗、升级、装备、技能、转职、任务和保存恢复；披风及全部物品类别需要真实获取与使用路径。

实现、规则测试、场景集成、画面检查和发行包测试分别记状态。现代化界面及美术在程序与功能测试阶段通过后实施，质量标准见[资源与交互](04-资源与交互.md)。
