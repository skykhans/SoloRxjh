# 职业创建与成长采用合同

更新日期：2026-11-13。状态：**部分项目设计，未实现，未通过D1冻结**。本页维护14职业的创建与成长映射，不替代[职业参考](reference/职业全览.md)或[历史证据](reference/职业创建差异与历史证据.md)。尚未闭合的属性、经验和技能参数明确列为阻止冻结的待办。

## 1. 单机创建策略

本项目设计所有职业从本地档案直接创建，不要求已有高等级角色、不充值、不连接服务器。每个新建角色均从1级、0转、未选正邪开始，已完成晋级与任务集合为空。**这是统一的新手剧情改编方案，不是声称官网所有职业都如此创建。**

乐师V8的“旧角色60级解锁、80级0转、124气功点、332750历练、初始+6装备”仅保留在历史参考库，不作为本项目初始化赠送。该方案消除跨角色解锁依赖，但必须为乐师补全1～79级可用武器、能力和成长过程；不能让低等级乐师无可用动作、提前借用80级技能或直接跳过应有任务。历史专属四转作为参考单独映射，不能把80级0转原始资料改成官方1级。

英雄职业保留各自武器、资源、动作和独立技能树，不替换成普通职业技能。官网明确的卢风郎/甄凤柏男性、东陵神女女性限制保留；其他职业两类体型是本项目外观选项，不作为官网创建性别已核实的证据。体型仅影响外观及装备适配，不增加隐藏属性。

## 3. 档案、创建事务与教程

最多3档案、每档案6角色是本项目容量设计，不是官网角色数。档案名2～16字、角色名2～12字按Unicode字符计数，首尾空白剔除后校验；禁止控制字符、纯空白和同档案规范化重名。名称先做Unicode NFC规范化并大小写折叠比较，不因全半角外观相近擅自合并不同汉字。角色和档案ID独立于显示名称。

创建顺序：选职业→可用外观→命名→预览→展示初始状态及改编说明→确认。预览不写存档、不发物品、不解锁任务。确认重新检查档案容量、重名、模板完整性、装备和能力定义，再一次生成角色ID、实例及初始存档。写入失败不登记半个角色；重复确认使用同一创建请求ID，不重复发物品。

教程按职业介绍移动、交互、对应武器、普攻、首个合法武功及特殊资源；教程奖励只对该角色结算一次，不给同档案其他角色发奖。方尘为剑客预设，不把浮仙剑认主作为其他职业全部动作的前置；其他职业与琉璃剑宗的衔接属于改编。

玩家可跳过教程说明，但不能跳过获取实际必需物品或把未完成任务写为完成。基础普攻、教学武功、初始道具与职业资源必须有明确配置；缺失模板时创建报出具体字段，不能借用剑客模板。

## 4. 等级与晋级分离

本项目当前等级范围设计为1～180，依据当前参考出现170～180怪物及升天七式内容确定体验范围，**不是官方最高等级已证实为180**。完整交付必须能达到170并完成十二转/七式；若后续最新资料要求扩大范围，先更新本合同及内容映射，不静默丢弃。

累计经验为等级唯一推导依据，经验阈值必须明确列出1～180级；不得以运行时默认曲线填缺项。满级经验处理、每级属性、气功点及历练来源尚未定值，当前阻止成长合同冻结。

## 6. 计划验收

逐个创建14职业，检查职业ID、允许外观、初始1级0转、无路线/无已完成晋级、独立实例与正确资源类型；不允许模板缺项后降级为剑客。测试容量、NFC等价重名、取消、连续确认及写盘失败，确认不产生半份记录或重复物品。

从1级至180级检查经验阈值、跨多级奖励去重、满级边界及保存往返；检查全部十二转及武器链、普通与英雄专属分支。医师和乐师应能独立通关；全部职业用实际技能树和独立资源完成战斗，不以文本面板代替。
