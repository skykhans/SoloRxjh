# 英雄武器合成与神物之石采用合同

更新日期：2026-11-14。状态：明确本地设计，未实现、未校准。权威参数为[合成与神物之石JSON](contracts/英雄武器合成与神物之石.v1.json)。

## 1. 来源与边界

甄凤柏专题确认神物之石可概率变更八大奇宝合成属性，血雨丸可用；四转/三式可取得。来源未给完整池和概率。本项目只采用六英雄主武器的四槽本地方案，不声称还原全部金刚石档位或把八大奇宝缩为官方六武器。金刚石名称有任务奖励来源，但本地获得、数值、概率、费用和属性选择均为项目设计。

初次合成适用107件主武器。神物之石变更适用其中stage≥4的83件，要求80级/rank4；这是项目门槛，不是官方已核条件。普通武器、防具及其他武器分支另行采用。

## 2. 合成槽与属性贡献

实例synthesis_entries为0～4项有序数组，slot_index必须从0连续，无缺口/重号；每项明确property_id、固定value和origin_receipt_id。初始空数组合法，缺字段或未知属性不是空槽。允许重复属性，最大四项。

| 属性 | 单项项目值 | 作用 |
| --- | --- | --- |
| 攻击增加 | 8 | 攻击上下限各加8 |
| 武功平威力 | 20 | 仅攻击武功平威力，不加普通攻击/治疗/状态 |
| 命中评分 | 15 | 当前有效武器的角色命中评分 |
| 回避评分 | 10 | 当前有效武器的角色回避评分 |

四项全同分别最多攻击32、平威力80、命中60、回避40。它们均标为synthesis，与属性石、真实强化和基础武器分开；卢风郎属性石翻倍不翻这些贡献。只读取生效装备组，不发点数、不增生命/内力或回血。

攻击武功平威力顺序为来源基础平威力+合法平加气功+真实强化平威力+合成平威力+具名觉醒平威力+具名属性石平威力（含合法卢差量），然后合计同范围百分比气功乘一次，再加入攻击并按原阶段系数处理。已接受动作保存来源快照，加工不会回改原攻击。晋阶、提真和转移保留合成项/收据血统历史，不把旧输出实例ID必须等于新实例ID当成合法性条件。

## 3. 三类服务

刀剑笑提供合成、神物之石制作及属性变更，公共门槛为本人存活、动作空闲、脱战、无挑战，同图可用NPC距离≤2.5米。武器操作仅本人装备背包，穿戴/仓库须明确卸下/取出，并验证定义的职业/等级/rank/路线。制作不需要武器输入，另检查80级/rank4、六英雄和正邪路线。

初次合成：明确选择池内属性，按下一个空槽提交；第1～4槽概率100/80/60/40%，每次1金刚石及5000两。成功追加一项，失败不增加槽且不损坏原装备/旧合成；两种结果都消耗该行成本。首槽必成不抽随机，后续一个[0,9999]整数，小于概率基点成功。满四槽不再合成，不偷偷覆盖旧项。

金刚石在刀剑笑不限量售价10000两，仅向六英雄售卖；堆99、10克、角色绑定，可仓储/丢弃，禁卖店/交易/复购/直接使用。单次首槽若购买材料共15000两。

神物之石制作：5金刚石+200万两→1石，必成、不抽随机；若材料全部购买总支出205万两。神物之石沿32合同原定义，不重复新增；两次甄任务奖励继续独立，制作不写或重置奖励阶段。

属性变更：选一已有槽，消耗1神物之石、手续费0，50%成功。失败保原项、不再抽属性；成功从其余三属性按池稳定顺序均匀选一个，更新该槽property/value/origin_receipt，保证属性发生变化，不改变槽数、强化、武器stage或真标识。每个新属性总概率1/6，失败1/2。成功失败都耗石，不自动退石或重试。

## 4. 原子性与保存

预览绑定实例、槽、属性、材料、修订和命令ID，展示概率及所有结果。未知/坏字段、其他成长不兼容或附加强化提升附着时先拒绝，不清字段兜底。制作只减材料后检查输出空间和最终重量；扣5石但原堆仍有余量时不能误算腾槽。武器处理保持实例ID和其他合法状态，不新增装备槽。

所有条件/空间通过后才克隆随机并计算；随机整数必须均匀，不能用有偏取模。成本、项变更或制作输出、随机状态和收据同笔提交。取消/不足/过期不动资源或随机；重复命令先查原收据，不按新槽重抽。保存失败只重试保存已提交结果。LAN使用请求者钱物/武器/随机，队友不代付或分输出；读档拒绝坏槽、值、收据与血统，不自动修复。
