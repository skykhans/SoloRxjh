# 62 普通防具成长结构与校验合同

更新日期：2026-11-14。状态：组件结构已采用，未实现。唯一合同为[普通防具成长.v1.json](contracts/普通防具成长.v1.json)，结构约束为[普通防具成长.schema.json](contracts/普通防具成长.schema.json)。

## 范围与字段

覆盖51普通防具1219件和55武勋防具106件，共1325件。77条基础防御阻塞、21件门派来源及旧初始短衫不纳入本组件。

现有实例平铺登记十字段：`enhancement`、`synthesis_entries`、`awakening_stage`、`element_attribute`、`evolution_tier`、`true_equipment`、`merit_equipment`、`four_divine_state`、`jade_attributes`、`enhancement_boost`。不新增嵌套容器。身份、血统、修订、位置和绑定仍由完整实例管理。

结构schema只约束十字段投影，拒绝缺字段、额外字段及错误类型。完整根实例必须先检查白名单和库存唯一性，不得通过提取投影隐藏未知根字段。结构通过不代表完整实例、档案、收据或角色资格通过。

## 校验顺序

解析阶段拒绝重复键及非法数，保留数字token类型。整数字段拒绝布尔、小数、指数和字符串；标准JSON Schema会接受数学值为整数的`1.0`、`1e0`，因此必须另查原始数字token。不能在Godot解码后强转整数补救。

随后验证完整根实例与库存，再验十字段结构、逐件能力上限和精确真/武勋布尔标识，再由52～61各owner验证属性池、连续槽位、阶段、成功收据及同血统历史。59的typed元素导入和60的实例替换仅授权各自明确的来源链，不能泛化成任意历史放行。

最后按当前命令验证角色、位置和加工资格。暂时失去穿戴资格不清除合法成长；临时提升仍按61计时。加工结果在副本上重新完成根、结构、语义、历史及最终格重检查后原子提交。转移双实例、提真旧新实例均须检查。

## 新建与读取

正式新建路径显式写入强化/觉醒/进化为0，合成/奇玉为空数组，元素/四神/临时提升为null；真与武勋标识逐件取精确定义布尔值。每件使用独立实例身份及血统。

上述新建规则不能修复旧档缺字段，不能按名称猜迁移，也不能套用旧初始短衫。未知元素或药品状态必须拒绝，后续采用需显式扩版。

Draft 2020-12结构schema检查通过；1325个新建投影通过，30个非法结构或严格数字样例被拒绝。另验证`1.0`可以通过标准integer但被严格数字检查拒绝，未知四神名称可以通过结构而必须交由语义owner拒绝。这些是静态验证，不是运行、存档、收据或LAN测试。

完整1325件根schema另由下节采用；完整档案/实例收据、其他元素/药品/特殊触发、预算及资源经济服务联审仍待。本组件不代表D1通过，不注册运行服务。


## 完整根实例与来源入口

[普通防具实例JSON](contracts/普通防具实例.v1.json)及[完整根schema](contracts/普通防具实例.schema.json)精确覆盖1325个正式item_id。根为8元字段加上述十个平铺成长字段，共18键；成长字段通过URN引用既有schema属性，不复制成另一套成长规则。

8元字段为instance_id、item_id、lineage_id、owner_character_id、binding、revision、creation_receipt_id、state_origin_receipt_id。全部character绑定；正文在equipment_instances唯一持有，位置只由容器/装备槽引用，不在实例加入位置、数量或派生属性。普通/武勋标识仍须等于精确定义，结构通过不替代逐件能力和历史检查。

正式首次生成revision=0、全新身份与血统，两根来源均指实际创建。state_origin是最近真实业务处理/配置/自然到期结果的前链入口；有费用及随机消耗的失败加工仍记结果、递增实例修订并更新入口，取消/拒绝/无变化配置不更新。原嵌套成功凭证保留，不能用最近来源覆盖所有成长出处。

60提真目标使用新实例ID、原血统/owner/绑定、revision=0，两根来源均指本次提真成功；旧创建与成长凭证沿同血统替换边保留，不能把新ID伪装成最初创建。59转移目标保原创建锚及血统，只更新修订/最新状态来源，源消费历史保留。

61日常remaining递减不改实例业务修订/来源，不每步分配收据；保存准确当前剩余及权威时钟，不能与最近业务收据的初始时长强求相等。到期置null生成一次状态结果并更新入口，修订沿共享时钟一次处理。完整时钟结果收据仍待。

旧兼容甲、初心短衫、21门派和77阻塞来源不套此schema，不补18字段猜迁移。1325当前出售/复购/玩家交易均禁止，通用迁移schema不改变权限。完整档案、全部实例收据/provenance、高级配置及其余D1仍待，运行服务保持关闭。
