# 乐师与格斗家普通武功采用合同

更新日期：2026-11-14。状态：**项目设计，未实现、未冻结**。[参数JSON](contracts/乐师格斗普通武功.v1.json)维护39乐师及19格斗普通攻击武功、2条格斗基础动作映射。这里只覆盖普通攻击条目，不将绝命技与升天混入单阶段常规攻击。

## 1. 来源划分与共享规则

[原表](reference/武功气功参数.json)17的54行分为39普通攻击、3心血绝命技、12升天条目；表19的36行分为2无威力基础动作、19普通攻击、3绝命技、12升天条目。所有行均有明确归属，绝命技已由[26合同](26-绝命技与终结收益采用合同.md)独立采用，升天条目仍待，不跳过也不当作已经完成。基本拳术/腿法映射22已定义的`basic_fighter`普攻表现，不另发两项已学武功、不把原空威力填0。

58能力显式引用[24共享学习/执行规则](24-六职业普通武功采用合同.md)：本人武功库、存活/非战斗/空闲/无挑战、职业/等级/晋级/路线、历练10L²和银两100L一次提交；最高一阶段、无书/材料/额外前招，不自动学招或换槽，条件失效保留但禁用。格斗原表无派别栏，本地这19项明确通用，不因此开放其正邪升天技能。共享规则是具名组合，缺能力/动作仍报错，不凭职业自动套动作。

## 2. 乐师攻击与和弦

39招的原表没有威力，明确采用24的平量4L，基础内力4+向上取整(L/5)+2，具体施法/投射参数见JSON。它们是单目标弦琴术法，倍率1.0、冷却90步；10～30教学后技能、35以后正邪路线和1～79乐师成长衔接不依赖历史80级创建赠装。完整装备/奖励路径仍待。

每个根动作第一次真实敌方命中只处理一次和弦选择，未命中、免疫或几何拒绝不处理；护盾全挡生命损失但确实命中仍可处理。本人存活并保持合法生效弦琴才可取得和弦。已满足梅花三弄条件时按14概率判一次，成功等概率选三/七/九；失败或未具该气功时按合法默认/自设循环前进一步，none从首项开始。两条分支互斥，不先循环再随机切第二次，也不额外消费另一次气功随机。

攻击快照继续使用接受时旧和弦，新状态仅影响后续动作；不得命中后用新九和弦重算本次威力。基础和弦600步、同状态刷新不叠加，循环设置/资格及失武器清理归14；岳阳/鸾凤/三潭等增幅归具名联动合同，不能三倍整个角色。根动作标记与选择/随机收据同笔保存，读档、重连或多段不再次转弦。

## 3. 格斗威力与连击职责

19招保留公开平量威力37～695，不另叠4L。三截拳按原基本连击分类采用三次根命中，活动段0/6/12步，各段完整平量37后乘0.4；这段数/时点/倍率为项目选择，不能把37先乘三再给每段。其余18招明确一次单目标、非连击、倍率1.2；具体前摇/活动/恢复/家族/射程见JSON。

三截拳受具名连击气功规则约束，每根最多一次追加家族；不触发磨杵成针非连击分支。其他18招可按磨杵成针非连击规则，不能据名字含“影/旋/升龙”猜出多段、击飞或瞬移。所有次数、命中随机、费用和去重继续走23/24。
