# 六职业普通武功采用合同

更新日期：2026-11-14。状态：**项目设计，未实现、未冻结**。[参数JSON](contracts/六职业普通武功.v1.json)唯一维护刀、剑、刺客、枪、弓、医师六表共234项普通攻击武功。它们是完整能力库条目，不以四快捷槽裁剪。乐师/格斗58普通攻击另见[25合同](25-乐师与格斗家普通武功采用合同.md)，12绝命技见[26合同](26-绝命技与终结收益采用合同.md)，英雄普通另见[27合同](27-英雄普通武功与阶段采用合同.md)，升天主动另见[28合同](28-升天武功与秘籍采用合同.md)。

## 1. 来源与采用边界

来源为[武功原表](reference/武功气功参数.json)表0、3、6、9、12、14，每表39行：3通用、18正派、18邪派。逐行保存索引与紧凑UTF-8 JSON行SHA256，保留原招式分组，不因剑表使用“密传枪法”而改写源文。名称、等级、正邪是源事实；原表没有给出这些技能的威力、费用、阶段和具体攻击形状，下列数值明确是项目设计。

本地每项只有一阶段，原等级10～108是人物学习条件，不是十阶段。最低角色晋级按10～34一转、35～59二转、60～79三转、80～99四转、100～108五转承接；等级足够但未完成晋级仍拒绝。正邪能力只向对应路线开放，通用允许未选或任一路线。不得从武器晋阶推断角色晋级。

## 2. 学习、保留与换槽

玩家在本人武功库主动学习，需存活、非战斗、空闲且无进行中挑战，完整满足职业/等级/晋级/路线。消耗历练`10×学习等级²`和银两`100×学习等级`，不扣气功点、升天点、书或材料。无额外前置武功/NPC条件是项目明确选择，避免未定义服务阻断普通树；并非官网免费学习结论。

一次学习只授一项一阶段，不自动学同招式组、另一派或下一等级；重复请求重放原结果，重复新请求拒绝，不再扣费。费用、能力记录、版本及事务收据一次提交，保存失败只重存原结果。升级/晋级不自动学技能，也不自动换快捷槽，11原创教学继续按22合同保留。

暂降等级/晋级或配置改路线时保留已学身份，但条件不足的能力不可用，不自动转成另一派、不退历练或银两；配置例外按18预览并标明。二阶段以上请求拒绝，不虚构升级配方。升天初始化不清这些普通一阶段能力，也不返天机石。

## 3. 威力、费用与职业动作

每段基础平量威力`4×该能力最低学习等级`；这是固定定义输入，不随当前人物等级再乘。与接受动作时已包含武器的最终攻击区间相加，按本段倍率取整，再走23的命中/暴击/减伤及具名气功。内力基础费`4+向上取整(学习等级/5)+职业偏移`，每个根动作付一次，后续恢复/减耗按已有合同结算；无体力、生命或箭矢物品费。设计意图为新招平量提升、旧招仍可操作，实际经济/输出平衡在T校准。

前摇/活动/恢复、投射速度/半径/存活和武器家族在JSON六个具名动作档完整列出。刺客明确为双段连击武功，其余五类单段；刀枪多目标不等于连击。医师这些是攻击武功，不因职业把伤害变成治疗；单招名称不自动产生控制、出血或恢复。职业气功/辅助/资源仍按各具名合同触发。

施法先有合法原主目标、距离、视线及兼容生效武器，付费后锁方向。命中逐段复验几何/遮挡与目标，原主目标优先，再按距离/稳定ID补目标；目标失效不偷换根主目标。远程真实碰撞首敌/固体，拦截者不成为反气功的新主目标。枪客副目标基础伤害50%，灵甲爆发按其具名合同替换至最多80%，只执行一次；刀客副目标100%不套枪规则。射程具名增益按其合同应用，投射寿命在接受时按有效射程×60/速度向上取整，不受原短射程寿命再次封顶；动作所有目标/段共享一次费用，怒气/出血/反气功等仍遵动作级限制。缺武器家族、正式定义或资源时报错，不能借教学能力代行。

## 5. 阶段审查与计划验证

D1检查234唯一ID、6×39源行及指纹、各职业3/18/18路线守恒、最低晋级/费用整数、动作全部必需字段、刺客两段和6职业模板可衔接、所有本地链接。10级能力学习费1000历练/1000两、平量40、内力6（枪/医8）；108级为116640历练/10800两、平量432、内力26（枪/医28）。刺客两段各用完整平量再乘0.55，不能先把平量除半后再乘一次。

P/T检查逐条学习/施放/保存、错误职业/派别/等级/晋级/重复学习、差1历练/银两和写盘失败原子性、换武器、手动换槽、刺客两段去重/中途目标死亡、刀枪目标上限/遮挡、箭矢拦截、费用一次及跨机权威结果。普通保存等待派生结束，活动按05保存完整动作/投射物/收据；重进不重付或重复伤害。开发表现资源ID已在动作档列明，文件在P实际制作/检查，不能把未制作写成已导入。

本合同只闭合这234项设计，不证明经济、技能树或职业已完整通关。完整其他主动、装备、地图、任务和掉落仍需D1闭合。
