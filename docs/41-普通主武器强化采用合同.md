# 41 普通主武器强化采用合同

[权威参数](contracts/普通主武器强化.v1.json)仅覆盖40合同447新定义；8初始武器保持上限0，2异常来源不进入加工，英雄、剧情剑、防具、首饰及宝珠各走自身合同。此为项目设计，未实现、未校准，完整普通成长尚未闭合。

## 材料、概率与失败

复用既有强化石唯一物品定义，500两、堆99、每颗10g。普通职业购买资格在本合同独立设计，尚未注册商店，不修改英雄商店筛选。强化NPC为刀剑笑，存活空闲脱战无挑战、同图可用且2.5米内，仅本人装备包中合格武器；装备先卸、仓库先取。

15阶参数在JSON逐项明列：前三阶必成，之后90%逐步降至+15的10%；材料1～15颗，费用100～1000万两。所有概率、费用及失败不毁、不降级、不清成长均为项目选择。前三阶不抽随机，其余房主只抽一次[0,9999]整数，以小于万分概率判成功。可选5%/10%/15%强化幸运符沿统一owner计算有效概率，未定义保护符/其他增益仍拒绝。

成功原实例真实强化+1，失败保留原真实强化；两种结果均扣精确石数和银费。伪造/未完成允许本项强化是项目选择，物品身份不会自动完成或提真。15拒绝加工；初始角色不赠石或强化。

## 攻击贡献与来源边界

4件正派刀炎玉圣刀、真-炎玉圣刀、天火圣刀、真-天火圣刀分别在14/15有8条可核对强化攻击行：普通382/602，真504/724。逐条引用原图参数，并验证原基础攻击加此值等于图示上下界。只在精确物品ID和真实强化组合采用，不扩大成全部武器官网公式。

其他合法组合采用明确项目曲线乘最低rank系数，真额外加1系数；源表未给的低阶值不标官网。具名8组与项目曲线互斥，只加一次。只有当前生效组武器贡献，包/仓/备用不叠。基础攻击不重写，不持久化派生缓存。

截图四条武功40+9+20%等为复合展示，本次不拆成完整普通强化武功公式，也不将气功、无视、命中、火属性混入真实强化攻击。相关贡献仍待采用，不能默认为零或因此宣称普通强化全部闭合；反气功、宝珠与15+[n]必须由各自owner采用。

## 事务与尚待闭合项

报价绑定实例、配方版本、角色/库存/实例修订和具名材料栈，展示成本及成功/失败完整派生变化。房主先查收据，再校验原库存合法，副本扣费与材料、检查最终格重，复制RNG后一次开奖，实例/资源/RNG/修订/收据一起提交。同命令返回旧收据，不重掷；保存失败只重存既定结果。

真实强化字段严格整数0～15，bool/float/string不合法，缺失不补默认；正式新建路径才可写0。其他合法成长字段原样保留，无正式schema或未知状态拒绝。完整普通实例schema、合成/属性/觉醒/四神/奇玉/进化、其他强化贡献、反气功/附加提升及世界商店服务注册仍待，当前不激活运行。

可选[5%/10%/15%强化幸运符](contracts/强化幸运符.v1.json)沿统一owner处理：每次最多一张，按精确物品分别加500/1000/1500bp、上限10000，不能叠加，原必成档选符拒绝；有效必成不抽随机，其余原单抽。成功失败均扣符，原成本/资格/失败保护不变；报价/命令摘要/收据绑定选符与基础/有效概率，取消/重试不重复消费。现有tier概率及随机标记是未选符的基础值，选符以统一owner计算有效值。此为项目采用，非官网未公开概率。
