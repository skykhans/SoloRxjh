# 英雄武器觉醒与四神采用合同

更新日期：2026-11-14。状态：明确项目设计，未实现、未校准；衣服仍待，当前三名NPC武者投影已明确。参数权威为[觉醒与四神JSON](contracts/英雄武器觉醒与四神.v1.json)。

## 1. 来源与本地采用

官网四神页明确玄武>朱雀>白虎>青龙>玄武；攻击取武器、防御取衣服，只能赋予有觉醒的武器/衣服，觉醒1阶段即可，赋予后可继续觉醒。四神独立于火毒。赋予手续费500万两，可用幸运符，变更券必成；来源NPC司空揽杰，原宝石有特定boss取得方式。

项目由现有刀剑笑提供服务/银价商店，不假造boss掉落已采用。觉醒五阶、各阶贡献/概率、100级/rank5/武器stage≥5门槛、宝石/券/专用幸运符名字与价格、对阵系数均为本地设计，非官网完整原值。

107件英雄武器的觉醒/四神字段有明确schema，其中stage≥5的77件允许加工。低阶武器仅觉醒0/四神null合法，不靠高等级角色把封印提前觉醒。衣服服务与其他普通装备另外采用。

## 2. 觉醒

awakening_stage为整数0～5；初始仍0。每阶给攻击上下限各6、攻击武功平威力12，五阶30/60；类别awakening，不被卢属性石翻倍，不发气功点或生命/内力。平威力与其他明确来源平加后，才进入百分比气功/阶段系数。不存派生属性缓存。

目标1～5阶各消耗集魂石1～5个、手续费100万×目标阶两；概率70/60/50/40/30%。成功只加1阶段，失败扣准确钱物但保原阶段/武器/其他成长。已赋四神后继续觉醒保留四神，不重收赋予费。

## 3. 四神赋予与变更

four_divine_state初始null，非空须有明确deity_id和来源收据；觉醒0+非空四神为坏状态，拒绝而不清四神或补觉醒修复。与element_attribute、合成、奇玉及宝珠分开保存，晋阶/提真/转移保留收据血统历史。

初赋需当前null、觉醒≥1，选择神并消耗对应宝石1个及500万两；70%成功，可选专用幸运符1个提升至80%。成功只设置所选神，失败保null，均耗所选钱物。预览绑定神/幸运符数量，不可抽后换选。

变更需当前已有神、觉醒≥1，选其余三神之一，消耗1武器四神之力变更券，手续费0，无额外宝石/幸运符，必成不抽随机。同神请求拒绝，不做付费空操作。

集魂石100万、四神各宝石500万、武器变更券1000万、专用幸运符200万两。七材料均堆99、10克、角色绑定，可仓储/丢弃，禁卖店/交易/复购/直接使用，刀剑笑不限量仅向合格六英雄出售；这些价格/权限为项目值，不折算商城元宝。

## 4. 本地伤害矩阵

25格明确覆盖双方各四神或无神。相克方向加10%，反向减10%，同神/对角不变；单方武器有神加10%，单方衣服有神减10%，双方无神不变。单方方向及正负幅度均为项目对来源未公开细节的取舍。

仅明确npc_martial_duel的敌对根普通攻击/攻击武功生效，普通野怪/非比武、衍生弹体额外攻击、状态/持续伤害/反伤/自耗不继承。攻击武器神取接受动作快照，防御衣服取命中时实际生效组；所有对手必须有明确采用的NPC武器/衣服投影，缺失不能猜无神，当前[卢90试练](contracts/气功学习与秘籍.v1.json)、[武勋教头](contracts/第六次升职与单机武勋试练.v1.json)及[十转证物教头](contracts/第十次升职五式与回忆录试练.v1.json)均显式采用固定属性、觉醒0、武器/衣服无神的本地方案，不复制玩家装备，不改原攻击/防御。入场保存版本化投影，读档沿原快照；缺失或非法则拒绝，不能由新版模板补齐。影子与回忆录守卫保普通BOSS分类。新手衣明确禁止四神，既有合法无神实例可投影为无神；其他衣服能力仍需独立定义。

在普通防御/平减及具名额外伤害处理后、百分比防护和护盾前，对该段伤害乘矩阵基点并向下取整一次，不重掷命中/暴击，也不倍增其他装备贡献。矩阵未知值报错，不默认为中立。

## 5. 事务与剩余工作

所有加工须本人职业/等级/rank/路线与武器条件符合，存活、空闲、脱战、无挑战，同图距刀剑笑≤2.5米；输入本人装备包，穿戴/仓库须先卸下/取出。源字段和额外提升附着不兼容时先拒绝，不丢字段。

预览绑定源/材料/角色修订、神/幸运符和命令ID。完整校验后才计算均匀随机；成本、结果、随机、修订和收据同笔提交。原槽同实例加工不新增装备槽，取消/不足/过期不动钱物或随机。重复请求先返回原结果；保存失败只重试已提交状态，LAN不共享队友钱物。

衣服觉醒/四神、未来新增NPC比武投影、其他属性、附加显示及反气功预算仍待。Godot加工/实际对阵/RNG/保存/LAN与经济尚未验证，D1整体未通过。
