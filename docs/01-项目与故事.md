# 项目与故事

更新日期：2026-11-13。开发代号 SoloRxjh，正式游戏名待定。目标为 **Godot 4.7.2 标准版 + GDScript 的 Windows 3D 单机武侠修仙 RPG**，系统与玩法参考《热血江湖》，界面与视听采用更现代的原创设计。

本次先完成文档，再处理程序实现与功能测试，最后落实美术与界面质量。当前工程仍为 Rust / Bevy；Godot 方案和新增功能均不能写成已完成。真实状态集中在[实施与验证记录](09-实施与验证记录.md)。

## 1. 产品定位

玩家在本地创建角色，通过任务、探索、打怪、武学、装备、强化合成和门派成长形成完整循环。启动、进入档案、创建/选择角色、保存、退出及再次继续均可离线完成。

《热血江湖》参考范围包括登录/选角流程、职业差异、武器与装备系列、主动武功与被动气功、等级/转职、怪物、任务、NPC 经济、披风和外观。已核对来源见[官网参考资料](11-官网参考资料.md)。玩法参考与原著故事各有来源，不能互相替代。

## 3. 角色创建与原有主角的衔接

旧版固定方尘、剑类战斗和单角色存档是迁移基线。目标版支持自建角色，输入姓名、选择职业及外观，角色身份为琉璃剑宗辖区中的江湖新人；方尘模板作为默认剑客预设保留。

这是为了角色创建作出的明确游戏改编：自建姓名、职业、性别/体型与经历不宣称属于原著。所有职业保留报到、领取差事、调查残剑与成长的教学职责；浮仙剑作为故事器物保留，非剑类职业的实战武器按职业授予，不能强迫弓手或医师使用剑类攻击。

旧存档导入后保留方尘身份与全部原进度，不自动改名、改职业或丢失装备。创建新角色与导入旧角色是明确的两种数据操作。

## 4. 场景与叙事职责

| 地区 | 叙事与玩法职责 |
| --- | --- |
| 千竹岭 | 杂役差事、工棚服务、残剑认主、采竹与入门战斗 |

工棚是安全与服务中心，曹斌负责主线和门派事务；铁匠、药师、仓管等服务角色按程序阶段加入。地图中的居民、敌人、交易与门派进度均由本地规则运行。

Q001～Q005、云溪谷与寒石古道、野兽和首领、职业及正邪路线、门派身份、经验、装备与奖励均为游戏设计。具体目标与数值只在功能和数值文档维护。

## 5. 叙事表现

开场、报到、取剑、认主、交差、首领回报和章节完成保留明确的前后顺序。短叙事可跳过，确认前不提前改写阶段；取消不授予器物或奖励。

首章主题保持“找到自己的成长道路”。剧情页和对话打开时暂停世界；叙事文本不遮挡长期操作，任务面板可回看当前目标和已完成步骤。不存在凭空显示在线玩家、服务器公告或虚构网络状态的界面。

## 6. 内容与素材边界

人物、世界和对白按“原著已核实 / 游戏改编 / 尚待核实”区分。参考《热血江湖》的系统组织和体验，自行制作模型、图标、场景、音效与界面，不提取商业游戏资源。现有原创模型、音乐、字体和许可继续维护。
