# 英雄武器奇玉采用合同

更新日期：2026-11-14。状态：明确项目设计，未实现、未校准。参数权威为[奇玉JSON](contracts/英雄武器奇玉.v1.json)。

## 1. 来源与采用边界

[六式强化转移FAQ](reference/升天六式强化转移规则.json)明确奇玉石是独立属性，普通转移不复制来源奇玉；未给完整属性池、槽数、英雄适用阶段或加工成本/概率。英雄专属转移按29合同的明确项目单源保留规则执行，不将普通FAQ解释为删除英雄奇玉。

本合同的单槽、三定值属性、材料、门槛、价格和成功失败行为都是项目方案。参考库中的官网未知项继续保留，不声称此池覆盖所有官网奇玉；普通武器和防具须独立采用。

## 2. 实例与加工

107主武器均有`jade_attributes`数组，空数组表示无奇玉；最多一项，保存property_id、精确value及origin_receipt_id。三种属性为攻击12、攻击武功平威力30、命中20，不抽属性数值，不将定值当百分比。stage不足4必须为空；六初始封印显式空数组，不赠材料或属性。

stage≥4的83件可加工，角色80级/rank≥4、正邪及本职业武器装备条件均须符合。刀剑笑同图2.5米，存活、空闲、脱战、无挑战，输入限本人装备包内合法未占用实例；穿戴或仓库物品先显式卸下/取出。附加强化等临时提升附着非零时拒绝，不抹字段。

三种具名材料分别售价100万、150万、80万两，刀剑笑库存不限，仅向80级/rank4六英雄出售。每种堆99、重10克、角色绑定，可仓储/丢弃，禁止出售、交易、复购和直接使用。购买仍检本人银两、格数、重量与修订。

赋予空槽或更换不同属性均耗对应材料1及20万两，成功率80%；成功得到所选定值、覆盖旧项且不返石，失败耗全部成本但保留旧项/空槽。相同属性输入拒绝，不借更换重刷收据。另可付10万两移除非空奇玉，必成、无材料、无随机、无返石；空槽移除拒绝。

## 3. 属性贡献与继承

只读当前生效武器。攻击12分别加到接受动作的攻击上下限一次；武功30进入攻击武功平威力池，在同范围百分比气功前合计，普通攻击/治疗/纯状态/衍生额外攻击不复制该项；命中20进入实际命中评分，不是20%命中率。

来源类别为jade，与强化、合成、觉醒和attribute_stone分开。卢属性石翻倍不倍奇玉；不发气功/反气功点、生命/内力，不恢复资源。

普通晋阶、提真、具名强化转移保留合法奇玉与原origin_receipt_id；替换武器的新收据记录继承关系，不伪造一次新赋予。不能因目标基础定义存在便跳过其他成长字段验证。

## 4. 事务与验证

先验证原库存合法和全部字段，再在副本计算成本/最终布局；原超重不能靠扣石修复。赋予/更换只抽一次均匀整数0～9999，小于8000成功，不抽第二次属性。钱物、奇玉、随机流、修订和收据同笔提交；取消、报价过期、条件不足不扣不抽。

重复命令先查收据，同ID不同负载拒绝；保存失败保留已提交内存，仅重存。LAN房主只用请求者本人资源。读档缺字段、非法值、多槽、坏来源链或重复血统直接拒绝，不补空或截断。

计划验收覆盖107绑定、阶段/职业/路线门槛、空槽/三属性转换、80%两结果、同属性拒绝、移除去重、转移保留、卢来源隔离及报价/保存/LAN失败。英雄进化另由[37合同](37-英雄武器进化采用合同.md)维护。静态检查仅证明字段、引用和算术，Godot运行与经济平衡仍待；D1整体未通过。
