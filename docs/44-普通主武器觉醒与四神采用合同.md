# 44 普通主武器觉醒与四神采用合同

[权威参数](contracts/普通主武器觉醒与四神.v1.json)为447件新普通武器登记字段，其中最低rank≥5的264件允许加工，另181件仅觉醒0、四神null合法。8初始武器、2异常来源、英雄/剧情剑/防具/首饰排除。此为设计，尚未实现或校准。

## 资格与共享范围

角色100级/rank5、已选正邪；同时满足武器职业/等级/rank/路线。刀剑笑同图可用且2.5米内，存活空闲脱战无挑战，武器在本人装备包，无占用且完整实例及原库存合法。最低rank是普通装备定义门槛，不新增英雄武器独立阶段。真、伪造、未完成按同一明确谓词分区。

七材料、四神ID与相克环、觉醒贡献及25格伤害矩阵显式共享现有唯一owner；普通资格、字段schema、配方及收据独立。材料价/堆重/权限不复制，普通商店适配器另注册，不修改英雄商店筛选。商店取得、门槛、觉醒数值/概率、失败保留、初赋概率和幸运增量为项目采用；500万初赋费、相克环及变更券100%沿来源。

## 觉醒与四神结果

觉醒0～5：第n阶耗集魂石n颗、100万×n两；成功率70/60/50/40/30%。成功同实例升1，失败扣材料及费用但保留全部字段。每阶生效武器攻击两界各+6、攻击武功平威力+12，按独立觉醒来源一次加入，不附气功/反气功点或生命内力。

觉醒≥1且无神时，报价前选一神及匹配宝石，耗宝石1和500万，基础70%；可选1专用幸运符增加10百分点，成功失败都耗。初赋成功写所选神及本次来源收据，不再抽随机神。

已有神用武器变更券1、手续费0选择另一神，100%且不抽样，无须宝石，不接受幸运符；同神拒绝。已有神继续觉醒必须保神，不将元素或合成互斥清除。

## 字段、战斗与事务

觉醒严格整数0～5，拒绝bool/float/string；低阶181件不能有正觉醒。四神显式null或deity_id/origin_receipt_id两字段，非空必须具名神且觉醒≥1。来源收据必须同角色同武器血统的普通加工成功结果，读档不补字段、不裁剪、不伪造历史。

四神使用共享矩阵：相克+10%、反克-10%、同神/对角不变，单方武器+10%、单方衣服-10%，均为项目幅度解释。仅明确NPC比武根直接攻击，攻击方读接受动作武器快照、防守方读命中时衣服或显式NPC投影；野怪、非比武、DoT、反射、衍生额外命中不乘。缺对手投影阻止活动配置，不猜无神。防具加工仍由自身合同采用。
